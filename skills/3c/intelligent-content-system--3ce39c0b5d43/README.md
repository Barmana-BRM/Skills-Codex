# Smart content creation and distribution system

> Word complete full process from content to multiplatform release

# Profile

The smart content creation and distribution system is a process-wide automation system that integrates five core skills and allows users to perform complex content creation and dissemination tasks by presenting needs in natural languages through smart scene recognition and workflow programming.

# Core characteristics

- ** Smart scene recognition**: automatic identification of 14 common scenes without technical details
- **  ** Auto-flowing**: smart call for 5 sub-skills to automate end-to-end
- ** Multi-platform support**: Support for Micro-Intelligence Publicise, Little Red Book, X/twitter, Site B
-** Real-time progress feedback**: clear indicators of progress for each step of implementation
- **  ** Flexible style custom**: supporting 10 little red book visual styles and 8 layouts

# Support the scene

# # Web Content Collection and Recreation (Category A)
- **A1**: Collection and distribution - Collection of web pages to optimize distribution
- **A2**: Collection and mapping - Collection of web-based smart maps
- **A3**: Collecting little red books - Collecting web pages to generate little red books

# # Hotspot content creation (category B)
- **B1**: Hotspot articles generated - collection of hotspots generated by AI articles published
- **B2**: Hotspot Image Generation - Collect hotspots to generate little red book graphics
- **B3**: Hotspot Multiplatform Release - Collect hotspot multiplatform distribution

Original content optimization and publication (C)
- **C1**: article graph - analysis of article graph
- **C2**: Twisted Red Book Graphics - Articles Small Red Book Graphic Series
-**C3**: Multiplatform release - Optimization of multiplatform distribution

## # Single function call (category D)
-**D1**: collection of web pages only
- **D2**: map only
- **D3**: Small Red Book only
-**D4**: published only

# Integration skills

The system integrates the following five core skills:

1. **baoyu-url-to-markdown** - Web content acquisition
- Use Chrome CDP technology
- Support JS rendering and login pages
- Output clean Markdown format.

2. **article-illustrator** - Smart article profile
- Analysis of article structure
- Identification of map location.
- Generate consistent illustrations

3. **boyu-xhs-images** - Small Red Book Graphic Generation
- Ten visual styles.
- 8 information layouts
- 1-10 graph series

**webcast-hotspot-publicsher** - Hotspot content creation
- Smart hot spots.
- The AI bomb case.
- Multiplatform release support

5. **content-creation-publicsher** - Content creation process
- Integration of the above skills
- Provide full workflow.
- Multiplatform Release Management

# Usage

Method 1: Natural language description (recommended)
Directly describing demand in natural languages, the system automatically identifies the scene and implements:

```
"采集这篇文章并发布到微信公众号 https://example.com/article"
"根据AI热点生成小红书图文"
"给这篇文章配图 article.md"
"把这个网页转成小红书图文 https://example.com/tutorial"
```

Method 2: Specify the scene code
If you are familiar with the scene code, you can specify directly:

```
"执行场景A1，URL是 https://example.com/article，发布到微信"
"执行场景B2，关键词是AI工具"
"执行场景C1，文件是 article.md"
```

##3 mode: step by step
For complex needs, they can be implemented in step:

```
"先采集这篇文章并配图"
→ 查看结果，满意后继续
"把刚才的文章发布到微信"
```
