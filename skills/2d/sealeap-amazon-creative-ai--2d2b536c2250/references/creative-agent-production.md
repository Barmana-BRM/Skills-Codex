# Creative Agent 生产与商品一致性审核

核验日期：2026-09-23。[Amazon Creative Agent 公告](https://advertising.amazon.com/resources/whats-new/unboxed-2025-creative-agent) 描述通过对话辅助广告构思并制作不同展示、视频及音频素材，入口包括广告控制台和 Creative Studio。公告公开范围包括美国；资格、支持格式和实际费用仍按目标账户当日入口核对。

本流程不依赖视频演示的时长或效果承诺。只有实际生成、人工审核与投放测试才分别报告相应结果。

## 生产前锁定

锁定 ASIN/子体、包装清单、真实形状/颜色/材质/Logo、允许场景、尺寸和性能证据；登记参考素材权利、人物/音乐许可、语言、广告位、技术要求和费用授权。未知能力标缺口，不造模型入口或 API。

用户明确要生成且授权已覆盖工具、素材与费用时进入 GENERATE；只要创意方案时交付 brief。当前工具不可用时给可移交脚本与素材表，不声称已出片。

## 分镜合同

逐镜记录：时间段、镜头任务、构图/动作、可见商品部位、字幕/旁白、证据 ID、需要实拍的细节与禁止改变项。时长、比例、编码及安全区取自当前广告位要求，不把横版素材直接裁切当作竖版完成。

## 共创与生成

1. 给工具商品事实、目标、品牌约束及分镜，保留 prompt 和版本。
2. 先核查低成本预览或概念；产品身份不一致时修正源图/约束，不靠后期文字掩盖。
3. 保存每个输出的素材 ID、输入资源、工具/版本、费用与时间。没有真实返回文件时状态仍为 PREPARED。
4. 用 [审核卡](review-and-testing.md) 检查完整视频，覆盖开头、结尾、转场及商品出现的每个镜头；抽帧不能替代完整播放。

## 一致性表

| 检查 | 不通过时 |
|---|---|
| 形状、颜色、部件、附件、数量 | 退回生成或替换实拍 |
| 尺寸/兼容性与实际功能演示 | 补证；无法证明则删除声明 |
| 字幕、标签、Logo 与本地化 | 人工修订再审核 |
| 场景暗示的功效、安全与结果 | 按实际证据和政策重新判断 |
| 无声/移动端可理解及裁切 | 为目标广告位重新设计 |
| 版权、人物、音乐、广告技术规格 | HOLD，不进入发布队列 |

## 交付与验证

产物及版本清单、逐镜证据和返工项、FACT/BRAND/POLICY/RIGHTS/TECH 审核结果、独立 A/B 卡。生产节省工时与广告 CTR/CVR/利润分别衡量；不得把生成成功当合规通过，也不把观察到的提升当因果证明。
