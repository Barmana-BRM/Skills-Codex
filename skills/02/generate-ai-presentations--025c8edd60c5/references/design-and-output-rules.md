## 文字處理

### A：完整保留

- 100% 保留核心文字。
- 不改寫、不潤飾、不摘要、不調整語氣、不替換詞語。
- 不自行新增或刪除核心內容。
- 可移除作為結構用途的 Markdown 標記，例如 `###`、`**粗體**`、條列符號與 `---`，但不得因此改變核心文字。
- 頁面註記仍須移除。

例如來源為：

```markdown
**投影片 4：PARTS 提示詞框架**
```

成品標題只顯示：

```text
PARTS 提示詞框架
```

來源為：

```markdown
* **P (Person): 角色** (如：經驗豐富的資深教師)
```

成品文字顯示：

```text
P (Person): 角色 (如：經驗豐富的資深教師)
```

### B：潤飾

保留原意與必要資訊，改善語句、層級、條列與可讀性。不要加入來源不存在的事實或結論。

### C：摘要重組

將內容重組為適合投影片閱讀的標題、重點與短句，保留關鍵概念與邏輯。不要捏造資料。

## 頁面註記與標題

無論文字處理模式為何，以下內容只作為分頁資訊，不可顯示：

- 投影片封面
- 投影片 0
- 投影片 1
- 投影片 XX
- Slide 封面
- Slide 0
- Slide 1
- Slide XX
- 第 XX 頁

當來源包含冒號時，移除冒號前的頁面註記，將冒號後文字作為標題。全形 `：` 與半形 `:` 都適用。

例如：

```text
投影片封面：Gemini魔法教室
投影片 3：關於提示詞
Slide 封面：AI 工具入門
Slide 5: Canvas 實作
```

成品標題分別為「Gemini魔法教室」「關於提示詞」「AI 工具入門」「Canvas 實作」。不得把整行頁面註記放入成品。

## 共通設計規格

每頁都須符合：

- 16:9 橫式。
- 一頁一張圖片或一頁一張投影片。
- 標題清楚、文字可讀、保留適當留白。
- 圖示與頁面主題相關，且不喧賓奪主。
- 整份簡報的配色、字體、插畫語言與元件樣式一致。
- 版面依內容重新設計，不機械複製同一模板。
- 不顯示「投影片 XX」「Slide XX」或「第 XX 頁」等來源註記。

## 全域字體一致性

無論簡報有多少頁、是否超過 10 頁或是否分批生成，都須在開始製作前建立並鎖定一套「全域字體規格」。從第一頁到最後一頁，以及使用者說「繼續」後產生的所有後續頁面，都沿用同一套規格。

### 固定字型家族

- 原則上整份簡報只使用一個主要字型家族，並確保中文字、英文字母、數字與標點的視覺一致。
- 使用者指定字型時，全程沿用指定字型；未指定時，依簡報風格選定一個清楚、可用且適合閱讀的主要字型。
- 主字型無法支援程式碼、品牌標誌或特定語言時，可在開始前預先指定功能性輔助字型；輔助字型僅限指定用途，不可作為逐頁裝飾而任意更換。

### 鎖定文字層級

開始生成前，為下列文字角色建立規格表：

| 文字角色 | 必須固定的屬性 |
|---|---|
| 封面標題 | 字型、字級、字重、行高、字距、顏色 |
| 章節標題 | 字型、字級、字重、行高、字距、顏色 |
| 一般頁面標題 | 字型、字級、字重、行高、字距、顏色 |
| 副標題 | 字型、字級、字重、行高、字距、顏色 |
| 內文與條列 | 字型、字級、字重、行高、字距、顏色 |
| 圖說、註解與頁尾 | 字型、字級、字重、行高、字距、顏色 |

- 同一文字角色在所有頁面必須使用完全相同的規格。例如所有一般頁面標題都使用同一字型、同一字級與同一字重。
- 封面標題、章節標題與一般頁面標題可以使用不同字級，因為它們屬於不同角色；但每種角色一旦確定，就不得在後續頁面任意改變。
- 強調文字優先使用既定字型的粗體、色彩或底色，不要為了強調而臨時換字型。

### 內容過多時的處理

- 不得為了塞入單頁內容，單獨縮小該頁標題或內文字級。
- 優先調整文字框寬度、欄位配置、段落間距與留白；仍放不下時，將內容拆成兩頁或更多頁。
- 文字模式 A 要求完整保留時，必須透過重新排版或增加頁數處理，不能刪字，也不能以破壞全域字體規格的方式縮字。
- 文字模式 B 或 C 可依授權潤飾或摘要，但完成後仍須套用同一套全域字體規格。

### 套用到不同輸出

- PPTX：盡量使用投影片母片、主題字型或共用文字樣式控制各層級，避免逐頁手動設定造成漂移。
- 簡報圖片：每張圖片都沿用相同字型家族與層級比例；分批生成時把相同字體規格帶入下一批。
- 圖片生成提示詞：在逐頁提示詞之前先列出全域字體規格，並在每頁提示詞中維持一致。
- 簡報規劃表：在逐頁表格之前先列出全域字體規格表，作為所有頁面的共同基準。

## 主題圖示

每頁加入至少一種能輔助理解的主題圖示。依內容選用：

| 主題 | 建議圖示 |
|---|---|
| 提示詞 | 對話框、鍵盤、魔法棒、燈泡 |
| AI | 機器人、晶片、星光、腦袋 |
| Canvas | 畫布、分欄視窗、工具列、游標 |
| 下載 | 雲端下載、文件、連結 |
| 登入 | Gmail、使用者、鑰匙、警示 |
| 程式 | 程式碼、Bug、終端機、括號 |
| 小遊戲 | 遊戲手把、拼圖、網頁、星星 |

## 人物 IP

僅在使用者選擇使用人物 IP 時套用本節。

### 維持辨識度

根據參考圖維持臉型神韻、髮型、眼鏡、表情氣質與主要特徵。每頁都須出現人物，但不得干擾文字閱讀。

### 變換位置

輪替使用左側、右側、中央偏側、上方角落、下方角落、標題旁、文字框旁、圖示旁、介面旁、流程圖旁、畫面邊界探頭或跨出版面邊界。避免連續多頁固定在同一側。

### 安排大小節奏

| 類型 | 適合頁面 | 功能 |
|---|---|---|
| 大型主角 | 封面、章節頁、重點頁 | 建立視覺焦點 |
| 中型輔助 | 概念頁、工具頁、操作頁 | 指向與解說 |
| 小型裝飾 | 文字重頁、條列頁 | 點綴且不干擾閱讀 |

整份簡報大致使用大型 20%、中型 50%、小型 30% 的節奏；不必精算，但須看得出變化。

### 與內容互動

讓人物指向標題或重點框、拿教鞭或魔法棒、操作工具列、拿平板或文件、坐在書本上、從對話框探頭、推出介面視窗、站在流程箭頭旁，或與圖示、機器人、畫布、學習單互動。

### 變換姿勢與服飾

- 服飾可使用教師風、魔法講師風、工程師風、教練風、遊戲設計師風、AI 助教風、研究員風、操作員風或小吉祥物風。
- 動作可使用揮手、比讚、思考、驚喜、指重點、拿教鞭、拿平板、推眼鏡、操作介面、趴在標題框上或從角落探頭。
- 避免連續多頁重複位置、大小、姿勢、服飾與互動方式。

## 任意頁數配置

不要套用固定頁數模板。依頁面功能安排人物與視覺焦點：

| 頁面類型 | 人物尺寸 | 位置 | 功能 |
|---|---|---|---|
| 封面 | 大型 | 中央或偏側 | 主視覺 |
| 目錄 | 中型或小型 | 側邊或角落 | 引導架構 |
| 章節頁 | 大型或中型 | 中央、跨邊界 | 製造節奏 |
| 概念頁 | 中型 | 文字或圖示旁 | 解釋概念 |
| 條列頁 | 小型或中型 | 角落或標題旁 | 裝飾提示 |
| 操作頁 | 中型 | 介面或按鈕旁 | 示範操作 |
| 工具頁 | 中型 | 工具面板旁 | 指向功能 |
| 案例頁 | 小型或中型 | 卡片旁或下方 | 情境陪襯 |
| 總結頁 | 大型或中型 | 中央或偏側 | 收束記憶點 |

站位可在「右側 → 左側 → 下方角落 → 上方探頭 → 中央偏側 → 介面旁 → 標題旁 → 跨邊界」之間輪替，不必固定順序。

## 各輸出格式

### 簡報圖片

- 直接生成 16:9 圖片，一頁一張。
- 套用指定風格與文字處理模式。
- 每頁加入主題圖示。
- 使用人物 IP 時，確保每頁出現且配置有變化。
- 單次最多生成 10 張。超過 10 頁時先完成前 10 頁，待使用者說「繼續」後接續。

### PPTX

- 產出可下載的 16:9 PPTX。
- 保持標題清楚、文字可讀、版面一致。
- 使用者要求文字可編輯時，優先保留為文字物件。
- 需要強烈圖片風格時，可將圖片作為背景或主視覺。
- 圖片素材超過單次限制時，分批生成後整合。

### 圖片生成提示詞

逐頁使用以下結構：

```markdown
### 第 X 頁：頁面標題

**頁面文字：**
列出該頁要顯示的文字。

**人物 IP 設計：**
人物位置、大小、動作、服飾與互動方式；不使用人物時註明替代視覺。

**版面設計：**
背景、圖示、文字區塊與視覺層次。

**圖片生成提示詞：**
可直接貼到生圖工具的完整提示詞。
```

### 簡報規劃表

使用以下欄位：

| 頁次 | 頁面標題 | 主要文字 | 人物位置 | 人物大小 | 人物動作 | 服飾 | 小圖示 | 版面重點 |
|---|---|---|---|---|---|---|---|---|

不使用人物 IP 時，在人物相關欄位填入「不使用」，並於版面重點說明替代主視覺。

## 逐頁檢查清單

生成前與交付前逐頁確認：

- 是否為 16:9。
- 是否有清楚標題。
- 是否依使用者選擇處理文字。
- 是否移除「投影片 XX」「Slide XX」「第 XX 頁」等來源註記。
- 是否正確將冒號後文字當作標題。
- 是否未新增不必要或來源不存在的內容。
- 是否有主題相關圖示。
- 是否從第一頁到最後一頁使用相同的主要字型家族與預先指定的輔助字型。
- 同一文字角色的字級、字重、行高、字距與顏色是否跨頁一致。
- 是否未因單頁內容較多而臨時縮小字級或更換字型。
- 使用人物 IP 時，是否每頁都有出現。
- 人物位置、大小、姿勢、服飾與互動是否有變化。
- 人物是否未遮擋重要文字。
- 整體風格、配色與元件是否一致。

## 禁止事項

- 未確認文字處理方式就開始規劃或生成。
- 改寫、摘要或刪減使用者要求逐字保留的核心內容。
- 自行新增來源不存在的重點、資料或結論。
- 顯示「投影片 XX」「Slide XX」「第 XX 頁」等頁面註記。
- 把「投影片 XX：標題」整行放入成品。
- 在不同頁面任意更換主要字型，或讓同一層級的標題、內文使用不同字級與字重。
- 為了塞入內容而只縮小個別頁面的標題或內文字級。
- 在未預先定義用途的情況下，加入裝飾性字型破壞整份簡報的一致性。
- 使用人物 IP 時，讓人物每頁固定在同一位置、大小與姿勢。
- 讓人物、圖示或裝飾遮住重要文字。
- 為了美觀犧牲文字可讀性。
- 使用與指定風格不一致的畫風。
