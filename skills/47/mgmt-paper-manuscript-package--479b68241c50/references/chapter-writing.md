# Chapter Writing

Each chapter should have a job. Do not let sections become storage for related text.

## Standard Chapter Jobs

- Abstract: compress question, method, finding, contribution, and implication.
- Introduction: create tension, locate the debate, preview evidence, state contributions.
- Theory: define constructs, explain mechanisms, derive hypotheses.
- Method: make sample, measures, identification, and analysis reproducible.
- Results: walk readers from design validation to main results, mechanisms, boundary conditions, and robustness.
- Discussion: convert findings into theory contribution, practical implication, limitations, and future research.

## Chapter Drafting Pass

For each chapter, generate:

1. Chapter purpose.
2. Required claims.
3. Required evidence.
4. Paragraph sequence.
5. Cross-references to other sections.
6. Reviewer risk.
7. Revision action.

Use short paragraphs. Keep one idea per paragraph. Avoid paragraphs that only announce what the next table shows.
