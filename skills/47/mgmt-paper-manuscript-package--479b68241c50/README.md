# mgmt-paper-manuscript-package

This skill organizes management paper materials into a reviewable manuscript package: inventory, evidence matrix, structure defense, chapter drafting, integrated revision, and presubmission package.

Install through the repository installer:

```bash
./install.sh --with-dev
```

Typical invocation:

```text
Use MGMT - Paper - Manuscript Package to turn my current materials into a presubmission package.
```
