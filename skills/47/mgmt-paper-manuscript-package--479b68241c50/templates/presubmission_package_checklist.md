# Presubmission Package Checklist

## Core Files

- Anonymous manuscript.
- Title page with author information.
- Cover letter.
- Abstract and keywords.
- Figures and tables in journal-ready format.
- Supplementary appendix.
- Data and code availability statement.
- Ethics, disclosure, and funding statements.

## Internal Review Files

- Evidence matrix.
- Structure defense memo.
- Revision log.
- Reviewer-risk memo.
- Style benchmark memo.

## Final Gate

Do not submit until every main claim maps to a table, figure, appendix, or clearly identified theory argument.
