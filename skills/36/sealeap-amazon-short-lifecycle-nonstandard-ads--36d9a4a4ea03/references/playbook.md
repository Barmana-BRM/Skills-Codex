# 短周期非标品的测款和退出

## 流量集中度

材料以寿司工具与装饰毯比较高/低集中度。使用同一站点、细分市场、时间窗和完整词集合，分别计算搜索、点击与购买份额；词形去重和主题合并需要明确规则，不能把重叠词重复计算。

源表用搜索量乘搜索转化率推算“出单量”，它属于特定数据口径下的估算，不是店铺真实订单或广告订单 CVR。只截取部分词时不称全市场 100%。

## 预算单位检查

- 新品例子：`200 件 × 39.99 美元 × 50% = 3999 美元`，原文约记 4000 美元，属于整个测款数量对应的预算假设。若要分日，需明确测款天数与每日上限。
- 成长例子：`20 件/天 × 39.99 美元 × 40% = 319.92 美元/天`，原文约记 320 美元/天。公式标题沿用了“测款产品数量”，实际例子已换为日销量。
- 50%-60% 与 30%-40% 来自讲师经验。比如广告前利润不足以承担这些比例，不能因课程写了该值就照用。

## 总损失与真实支出控制

先确认用户的上限是广告费、整个测款损益还是现金净流出。未售库存通常仍是资产，采购现金支出不能全部直接记成损失；另计可预见的减值、清货/处置和未包含在单件贡献中的费用，避免把已售采购、退货等重复扣除。

在相同试错范围内，可用 `预计损失 = 实际广告费 A + 其他损失及风险准备 R - 已实现广告前净贡献 M` 做核对。若评估的是广告因果增量，M 还需要相应对照证据，不能直接用全店自然销售抵扣。

保守的零销售情景下，广告总预算 `B ≤ max(0, 总损失上限 L - 其他损失保守上界 R_max)`，同时满足用户单独给定的广告/现金上限。未知的 R 不填 0，也不随意设一个预留比例就宣称闭合；R_max 无法界定时标为 `HOLD_FOR_LOSS_SCOPE`，继续补数据或输出明确的条件草案，不承诺总损失一定受控。不能用尚未实现的预测订单提前抵扣风险。若 R_max 已大于 L，即使广告额度取 0，总试错风险仍超出约束；应单列超额风险与库存/处置方案，保持 HOLD，不能报告为已经止损。

日预算是支出计划，不是已验证的实时硬限额。核对当前账户预算规则、自动增额、报告延迟、暂停生效及可能的未入账消耗；从剩余额度中留出可界定的尾部暴露。无法可靠核对累计消耗时，不继续释放新的阶段资金。

## 无历史 CVR 的探索与阶段释放

先选少量可解释、相关的词/商品目标，按剩余损失空间给出阶段资金上限和按目标的成本检查点。没有成熟 CVR 时不提供确定的订单预测或假定平台建议 CPC 就可盈利。成本检查点是控制资金的约定，不是统计证明需求存在或不存在的阈值。

每阶段记录 `资金上限 / 相关性证据 / 点击与购买定义 / 归因成熟日 / 下一阶段释放条件 / 停止条件`。达到花费检查点且未见有效订单时，可暂停新消耗等待归因、复核流量或修复页面；短期零订单不等于市场无需求。预定阶段到期不自动加钱，单笔订单也不足以证明稳定转化。

把投放截止日、暂结日、归因成熟复核日及退货/库存结算日分开。测试最后两天停投不代表之前流量已经完成归因；等待成熟不会自动延长投放或增加预算。

## 测试顺序

1. 用真实属性与场景生成词和相关商品目标。
2. 通过有限点击和成本测试相关性、页面承接与购买意图。
3. 把已验证的流量按关键词/商品/场景归类，再考虑扩匹配、位置或品牌触点。
4. 否定明显不适用的属性时检查整词组对相关长尾的误伤，不用无限扩词代替证据。

素材必须忠实呈现商品，主图背景/文字/模特/配件要求按当前类目规则；不能用“换背景规避比价”作为违反规范的理由。清仓与 Final Sale 等标签、Outlet 和促销需核验资格及可使用字段。

## 下滑诊断

- 本品与同范围市场同时下降：检验季节、整体需求、价格和渠道变化。
- 市场上升而本品下降：检验竞品新品、款式替代、页面/库存/评价和真实流量份额。
- 先解释需求，再决定广告调整；不是所有下滑都能靠加价修复。

旧品好词迁移到新品前，核对产品事实和消费者任务；继承词库不等于继承转化。退出方案列剩余库存、处置成本、现金回收、截止日期与责任人。
