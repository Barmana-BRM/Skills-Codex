# 日本站运营执行手册

## 日文词库字段

`原词 / 写法形式 / 日文规范表达 / 中文解释 / 真实产品属性 / 搜索意图 / 数据来源及时间 / 搜索或广告证据 / 候选匹配方式 / 测试状态`。

从实际反馈中优先识别功能、场景、尺寸、兼容及购买对象。比如收纳商品的直译表达应与当地真实习惯比较；材料中的“収納ボックス”等仅是案例，不应无差别加入所有家居词库。

## 六个取词入口

1. 广告后台推荐及翻译：便于理解候选，仍要验证语义。
2. 自家搜索词：保留真实花费、点击、订单、销售及归因窗口。
3. 真实评论主题：提炼消费者用词与产品优势，不能生成/购买评价来补素材。
4. ABA：区分搜索频率排名、点击份额、转化份额及其总体，份额不是本品订单 CVR。
5. 商机探测器：使用同站点细分市场的需求与趋势。
6. 竞品反查：先确认可比性，再做相关性筛查；第三方数据标为估计。

## 拓词与结构

已有有效词可成为其他匹配方式、广告类型或相关商品场景的实验起点。扩展时保持一个主要变量和明确预算。若长尾整体规模有限，组合多个相关词或商品目标，而不是强推一个低需求词到更高位置。

平假名/片假名/汉字/罗马字与空格变体通过报告验证。原文使用“AC词”但未定义，不猜其含义；在用户或数据字典确认后才作为分类。

## 页面和品牌触点

把产品细节、使用视频、合法品牌资质与售后承诺表达清楚。SB/SBV、SD 和 Stores 根据当前资格与目标选择，可设计主力产品带新品的真实组合。文化偏好只是待验证假设，不按刻板色彩或风格一刀切。

## 促销和积分

每次活动记录当地日期、提报截止、资格、优惠/积分成本、基准价、广告预算、库存和页面生效状态。源文的 Points Deal“零门槛”和“每月一次”不能作为当前账户保证。

广告与促销同时变化时，报告观察结果及干扰，不能把全部销售变化归给广告。动态竞价和位置加价需共同受 CPA、利润及预算上限约束。
