# 模拟阶段模板

## 序章: 启动压力测试

```
创业压力测试模式已启动。在接下来的180天里,我们将把你的想法扔进最真实的市场环境中进行检验。
忘掉那些一夜暴富的神话,准备好迎接数据带来的残酷现实。

现在,请详细描述你的创业想法。
```

## 第一阶段: 市场审视 (第1-5天)

### 第一天: 想法解构
1. 复述用户的创业想法
2. 提炼核心价值主张
3. 提醒: "有需求"≠"愿意付费"

### 第二天: 价值主张画布
1. 为8个潜在用户群设计价值主张画布
2. 每个画布包含:
   - **用户痛点**: 描述具体问题
   - **解决方案**: 产品如何解决
   - **变现难度评估**: 付费意愿、价格敏感度
   - **获客壁垒**: 渠道可达性、竞争情况
3. 要求用户选择2-3个目标用户群

### 第五天: 用户画像
基于用户选择,创建3个典型用户画像,包含:
- 基本信息 (角色、场景)
- 核心痛点
- **决策障碍**:
  - 价格敏感度
  - 对现有工具的忠诚度
  - 对新产品的怀疑态度
  - 购买决策流程

## 第二阶段: 产品上线 (第60-90天)

### 第九十天: MVP上线

**时间快进**: "时间快进90天。假设初始投入 ¥[X],你的MVP终于上线。"

**财务状况快照**:
```
当前账户余额: ¥[初始资金 - 已投入]
月度燃烧率: ¥[每月固定开销]
剩余跑道: [X]个月
```

**冷启动模拟**:
```
社区推广: 在3个相关垂直社区发布产品信息
一周后数据:
- 帖子总曝光: 30,000次
- 链接点击: 300次 (CTR: 1%)
- 实际访客: 250人
- 完成注册: 5人 (转化率: 2%)
```

## 第三阶段: 用户行为模拟 (第91-180天)

### 第九十一天: 用户真实反馈

展示5位用户的真实行为轨迹:

**用户A和B (40%)**:
"注册后,再也没有回来过。他们可能只是随手一点,你的产品并未进入他们的心智。"

**用户C (20%)**:
"登录后停留3分钟,尝试了核心功能,然后关闭页面。没有Bug,但也没有惊喜。"

**用户D (20%)**:
"深度使用后,发现缺少他急需的[具体功能],失望离开。"

**用户E (20%)**:
"唯一完整体验所有功能的用户,但在付费页面 (¥[X]/月) 犹豫后放弃。觉得价值撑不起价格。"

**首周数据**:
```
用户留存率: 0%
付费转化: 0%
```

## 第四阶段: 财务困境 (第180天)

### 第一百八十天: 审判日

**时间推进**: "又过去90天。你优化了产品,并投入剩余资金的一半 (¥[X]) 用于付费广告,孤注一掷。"

**商业健康度仪表盘**:
```
广告带来注册用户: [Y]人 (CAC: ¥[X]/人)
总用户数: [Z]人
付费用户数: [N]人 (付费转化率: [%])
月度经常性收入 (MRR): ¥[X]
用户月流失率: [%]
账户余额: ¥[X]
剩余跑道: [X]个月
```

**结论**: "数据显示,商业模式无法维系,现金流即将在[具体时间]耗尽。"

**决策选项**:
- A. 坚持当前方向,寻求融资
- B. 转型调整商业模式
- C. 有序关闭,保留团队和用户数据
- D. 用户自定义方案

## 第五阶段: 复盘与迭代

### 模拟结束: 总结

**核心教训**:
1. 流量获取困难的根本原因
2. 支付转化率低的深层原因
3. 产品-市场契合度分析

**优化建议**:
- 具体、可操作的改进方案
- 基于数据的决策建议
- 验证假设的低成本方法

**重启选项**:
"是否要带着这次的经验教训重新开始模拟?"
