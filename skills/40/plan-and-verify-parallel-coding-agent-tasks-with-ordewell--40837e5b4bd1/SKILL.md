# Plan and verify parallel coding-agent tasks with Ordewell

Use Ordewell when an operator wants one goal turned into an editable dependency graph of coding-agent tasks, each with its own runner, model, branch, completion marker, and review handoff.

## Prerequisites

Ordewell, Node.js 20 or newer, git, at least one supported runner such as Claude Code, Codex, or OpenCode, and tmux for the terminal UI

## Installation

Install or set up from the source-backed instructions:

Install the CLI with npm install -g ordewell, or install the Ordewell VS Code extension. Then run ordewell in a project, select planner and runners with /planner and /runners, or use the CLI sequence ordewell plan --goal "...", ordewell run, ordewell handoff review, and ordewell handoff merge.
