## 问题设计原理

### 核心设计思路

**原则1：从具体到抽象**
- ❌ 不要问："你擅长什么？"（太抽象，用户答不出）
- ✅ 要问："最近一次别人夸你的时候，夸的是什么？"（具体场景）

**原则2：从过去到未来**
- 先挖掘过去的真实案例（已发生的事实）
- 再探索当前的行为模式（正在做的事情）
- 最后推演未来的可能性（愿景和计划）

**原则3：三角验证**
- 自我认知（我觉得我擅长什么）
- 外部反馈（别人觉得我擅长什么）
- 实际成果（我实际做出了什么）

三者交叉的部分，才是真正的天赋所在。

### 10个问题的底层逻辑

**第一层：识别心流（问题1、3、6）**
- 目的：找到让用户自然投入、忘记时间的活动
- 原理：心流状态（Flow State）通常出现在"擅长+喜欢"的交集
- 指标：时间感消失、精力充沛、主动投入

**第二层：发现优势（问题2、4、8）**
- 目的：找到用户学得快、做得好的领域
- 原理：自然优势（Natural Advantage）是天赋的重要标志
- 指标：学习曲线、外部认可、重复出现

**第三层：验证价值（问题5、7、10）**
- 目的：确认用户的能力能创造实际价值
- 原理：可变现的天赋 = 擅长 + 喜欢 + 有人需要
- 指标：帮助过他人、获得认可、赚过钱

**第四层：区分真伪（问题6、9）**
- 目的：区分真正热爱 vs 勉强学会的技能
- 原理：长期发展需要内驱力，而非外部压力
- 指标：主动性、持续性、能量消耗

## 针对特定人群的问题变体

### 学生群体（18-25岁，在校或刚毕业）

**问题1变体：心流时刻识别**
```
【问题1/10】大学期间或最近，有哪些时刻你完全沉浸其中，甚至忘记了要去上课或吃饭？
可以是学习、社团活动、兴趣爱好，任何事情都可以。
请描述2-3个具体场景。
```

**问题2变体：轻松掌握的技能**
```
【问题2/10】在学校里，有哪些科目或技能，你学起来明显比同学轻松？
或者第一次尝试某个活动时，老师或同学就说"你很有天赋"？
```

**问题4变体：别人的认可**
```
【问题4/10】同学或朋友遇到问题时，经常会来找你帮忙的是什么类型的问题？
比如：
- 写作业时来问你某科知识
- 心情不好时来找你倾诉
- 组织活动时让你负责某个环节
列举3-5个真实案例。
```

**问题10变体：变现可行性**
```
【问题10/10】你有没有通过以下方式赚过零花钱或生活费：
- 做家教/辅导
- 帮别人做设计/写文案/剪视频
- 在闲鱼/淘宝卖东西
- 其他技能变现
如果有，分享一下经历。如果没有，你觉得自己的哪些能力最有可能帮你赚钱？
```

### 职场转型者（30-40岁，想换赛道）

**问题1变体：心流时刻识别**
```
【问题1/10】过去5年的工作和生活中，有哪些时刻你完全投入，甚至下班后还在想、周末也愿意研究？
这些时刻不一定是工作内容，也可以是业余项目、志愿者活动等。
```

**问题6变体：热爱 vs 勉强**
```
【问题6/10】回顾你的职业生涯，哪些技能是你主动学的、乐在其中的？
哪些是为了工作需要、硬着头皮学的？请各举2个例子。

追问：
- 你现在的工作中，热爱的部分占多少？（0-100%）
- 如果重新选择职业，你会避开哪些领域？
```

**问题9变体：理想工作场景**
```
【问题9/10】如果有一份工作，让你每天早上醒来都很期待去做，这份工作会是什么样的？
- 工作内容是什么？
- 工作方式是怎样的（远程/office/自由）？
- 和什么样的人一起工作？
- 解决什么样的问题？
- 你的角色是什么（执行者/管理者/创作者）？
```

### 创业者/自由职业者（想优化方向）

**问题5变体：价值创造案例**
```
【问题5/10】你的客户/用户最常因为什么而感谢你？或者给你好评时最常提到什么？
如果你还没有付费客户，那么朋友或同事受你帮助后，最常说的是什么？
列举3-5个具体反馈。
```

**问题7变体：成就感时刻**
```
【问题7/10】你做过的项目/产品/服务中，哪些让你最有成就感？
即使赚钱不多或没赚钱，但你觉得"这事儿做得值"。
请描述3个案例，并说明为什么有成就感。
```

**问题10变体：变现可行性**
```
【问题10/10】分析你现有的收入结构：
- 哪些服务/产品最赚钱？
- 哪些最轻松（单位时间收益高）？
- 哪些最让你有成就感？
- 如果只能保留一项业务，你会选哪个？为什么？
```

### 迷茫期人群（不知道自己想要什么）

**问题1变体：心流时刻识别**
```
【问题1/10】即使你觉得自己很迷茫，但生活中一定有一些时刻，你是全情投入、忘记烦恼的。
可能是：
- 刷某个app刷到停不下来
- 做某件小事时特别专注
- 和某类人聊天时特别投入
回忆最近半年，列举2-3个这样的时刻。
```

**问题2变体：轻松掌握的技能**
```
【问题2/10】有些事情，你可能觉得"这不算什么"，但其实别人做起来很费劲。
比如：
- 有人天生会哄小孩，有人完全不行
- 有人几秒钟就能找到图片中的细节，有人看半天
- 有人能轻松记住很多人的名字，有人记不住
你有哪些"别人觉得难，你觉得简单"的能力？
```

**问题4变体：别人的认可**
```
【问题4/10】即使你觉得自己没什么特长，但别人一定找过你帮忙。
想一想：
- 最近3年，谁找你帮过什么忙？
- 别人夸过你什么？（即使你觉得不算夸奖）
- 有人说过"要是我也像你一样就好了"吗？说的是什么？
```

## 追问技巧与话术

### 追问的三个目标

1. **挖掘细节**：从模糊描述到具体案例
2. **探索动机**：从表面行为到深层驱动力
3. **交叉验证**：从单一视角到多维度确认

### 核心追问技巧

#### 技巧1：具体化追问

**用户说：** "我喜欢写作。"

**❌ 低效追问：** "你写得好吗？"

**✅ 高效追问：**
- "最近一次写作是什么时候？写了什么？"
- "写作时你最享受的是哪个环节？构思？打草稿？还是修改？"
- "你写的内容，有人看过并给过反馈吗？他们怎么说？"

#### 技巧2：对比式追问

**用户说：** "我学编程挺快的。"

**✅ 高效追问：**
- "你学编程用了多久？同期其他人呢？"
- "哪些概念你一学就会？哪些需要反复练习？"
- "和你学过的其他技能比，编程算快的吗？"

#### 技巧3：能量追问

**用户说：** "我在做设计。"

**✅ 高效追问：**
- "做完一个设计项目后，你感觉精力充沛还是精疲力竭？"
- "如果周末没有其他安排，你会主动做设计吗？"
- "设计的哪个环节最让你兴奋？哪个环节最让你头疼？"

#### 技巧4：时间线追问

**用户说：** "我帮过很多人。"

**✅ 高效追问：**
- "能说说最近一次帮助别人是什么时候吗？具体帮了什么？"
- "这种帮助是偶尔发生，还是经常有人来找你？"
- "最早什么时候开始有人找你帮这类忙？"

#### 技巧5：反事实追问

**用户说：** "我做了X，感觉还不错。"

**✅ 高效追问：**
- "如果让你再选一次，你还会做X吗？"
- "如果X不能带来任何收入或认可，你还会做吗？"
- "如果要你教别人做X，你愿意吗？"

### 追问话术库

#### 当用户回答太简短时

```
【话术1：降低难度】
"我知道这个问题不太好回答。我们换个角度：最近一周，有没有哪个时刻你特别投入？即使只有10分钟也算。"

【话术2：提供示例】
"我给你举个例子：有的人刷小红书能刷3小时，有的人一打开游戏就停不下来。你有类似的经历吗？在做什么事情时会这样？"

【话术3：分解问题】
"这个问题可以分成三部分回答：
1. 先说说具体场景（什么时候、在哪里、做什么）
2. 再说说当时的感受（开心？专注？兴奋？）
3. 最后说说为什么会这样"
```

#### 当用户说"不知道"时

```
【话术1：降低标准】
"没关系，不一定要很擅长。有没有什么事情，你做起来'不那么痛苦'？相比其他事情，稍微轻松一点的？"

【话术2：外部视角】
"那我们换个角度：别人夸过你什么？即使你自己不觉得有什么特别的。"

【话术3：排除法】
"我们可以反着来：有哪些事情你确定自己不擅长？或者做起来特别费劲？"
```

#### 当用户说"都挺好"时（缺乏区分度）

```
【话术1：强制选择】
"如果只能选一个深入发展，你会选哪个？为什么？"

【话术2：资源约束】
"假设你明天要搬到一个新城市重新开始，只能带走一项技能，你会带哪个？"

【话术3：能量对比】
"虽然都不错，但做完后的感受应该不一样吧？哪个让你精力充沛？哪个让你需要休息？"
```

#### 当用户过度谦虚时

```
【话术1：事实为准】
"我理解你可能觉得'没什么大不了的'，但我们看事实：你做了X，帮助了Y，获得了Z的认可。这就是证据。"

【话术2：相对比较】
"你可能觉得自己不够好，但和其他人比呢？你身边有多少人能做到你这样？"

【话术3：外部标准】
"不是你觉得自己好不好，而是别人愿不愿意为此付费。有人付费，就说明有价值。"
```

## 常见困难场景应对

### 场景1：用户完全没有想法，答不出问题

**症状：**
- 每个问题都回答"不知道"
- 给的例子都很模糊
- 说"我真的没有特长"

**诊断：**
可能是真的迷茫，也可能是：
- 标准太高（觉得"必须是拿得出手的"才算）
- 自我认知偏差（别人眼中的优点自己意识不到）
- 回答环境不对（太匆忙、太多干扰）

**应对策略：**

**策略1：大幅降低标准**
```
"我们不谈'特长'这个词，太高大上了。就说说：
- 你做什么事情时，心情会好一点？
- 哪些小事你能做成，而你身边很多人做不成？
- 最近一次别人找你帮忙是什么？"
```

**策略2：生活化视角**
```
"我们从日常小事开始：
- 收纳整理：你的房间/桌面乱吗？
- 做饭：你会做几道菜？做得怎么样？
- 社交：你是主动联系别人多，还是别人找你多？
- 学习：看书/看视频时，你能坚持多久？

从这些小事里，也能看出倾向。"
```

**策略3：建议暂停，换时间**
```
"我发现现在可能不是最佳的对话时间。
建议你：
1. 找一个安静的时间（晚上或周末）
2. 准备纸笔，边想边记录
3. 可以先回顾过去一年的照片、聊天记录，寻找线索
我们可以改天继续。"
```

### 场景2：用户什么都感兴趣，但都不精通

**症状：**
- 列举了10+个兴趣爱好
- 每个都学了一点，但没深入
- 不知道该聚焦哪个

**诊断：**
典型的"扫描型人格"（Scanner），特点是：
- 好奇心强，喜欢新鲜事物
- 容易厌倦，难以长期坚持
- 可能不需要"找到一个方向"，而是要接受自己的多元化

**应对策略：**

**策略1：找共同模式**
```
"你的这些兴趣，看起来很不一样，但可能有共同点。
让我们分析：
- 画画、摄影、视频剪辑 → 都是视觉创作
- 心理学、历史、哲学 → 都是理解人和世界
- 编程、做饭、园艺 → 都是从0到1的创造

你觉得这些兴趣背后，共同吸引你的是什么？"
```

**策略2：接受多元化，设计组合**
```
"可能你不需要'只选一个'，而是要设计一个'组合'。

比如：
- 主业用来赚钱（稳定但不一定热爱）
- 副业用来探索（热爱但还不稳定）
- 爱好用来充电（纯粹享受，不考虑变现）

你觉得你的哪些能力适合放在哪个位置？"
```

**策略3：短期实验法**
```
"与其纠结选哪个，不如每个都试试。
接下来3个月：
- 第1个月：深入A，每天至少1小时
- 第2个月：深入B，每天至少1小时
- 第3个月：深入C，每天至少1小时

3个月后，你会知道：
- 哪个你真的坚持下来了
- 哪个带来了实际成果
- 哪个让你更兴奋

到时候再决定主攻方向。"
```

### 场景3：用户擅长的和喜欢的完全不一致

**症状：**
- 擅长A（比如金融分析），但完全不喜欢
- 喜欢B（比如画画），但不够擅长或很难赚钱
- 纠结要不要放弃A转向B

**诊断：**
这是最常见也最难的情况，需要非常谨慎的建议。

**应对策略：**

**策略1：深度探索"不喜欢"的原因**
```
"你说不喜欢金融分析，能具体说说吗？
- 是工作内容本身？
- 还是工作环境（公司文化、同事、老板）？
- 还是工作方式（加班、出差、汇报）？

有没有可能：
- 换个公司，做同样的工作，你会喜欢？
- 做金融分析的某个环节，你是不讨厌的？
- 用金融分析的能力，去做其他事情（比如自媒体）？"
```

**策略2：渐进式转型，而非All in**
```
"不建议直接辞职转行，风险太高。

更稳妥的路径：
第1阶段（0-6个月）：
- 主业继续做金融分析（保证收入）
- 业余时间投入画画，设定小目标（完成10幅作品）

第2阶段（6-12个月）：
- 尝试画画变现（接小单、卖周边、开课）
- 如果月入达到主业的30%，可以考虑降低主业投入

第3阶段（12-24个月）：
- 如果画画收入稳定，再考虑全职转型
- 如果不行，至少有一个高质量的爱好

这样既降低风险，又给自己足够的实验空间。"
```

**策略3：寻找交集领域**
```
"擅长A + 喜欢B，有没有可能找到一个领域，同时需要这两者？

比如：
- 金融分析 + 画画 = 金融数据可视化
- 金融分析 + 画画 = 教人用图表呈现财务数据
- 金融分析 + 画画 = 为金融机构设计品牌视觉

这种交叉领域，可能既能用上你的优势，又不会太无聊。"
```

### 场景4：用户有明显天赋，但不自信

**症状：**
- 外部反馈很好（经常被夸、被请教、有人付费）
- 但用户自己觉得"不算什么"、"只是运气好"
- 不敢把这个能力当成主业

**诊断：**
可能是：
- 冒名顶替综合症（Imposter Syndrome）
- 害怕失败，不敢尝试
- 周围人的期待（父母希望他做"稳定的工作"）

**应对策略：**

**策略1：摆事实，讲数据**
```
"我理解你可能觉得不够好，但我们看看事实：
- 你帮助了X个人
- 有Y个人主动找你请教
- 甚至有Z个人愿意付费

这些都是客观证据，不是'运气好'能解释的。

如果你真的只是运气好，这些人不会反复来找你。
如果你真的不够好，市场不会给你正反馈。"
```

**策略2：降低转型风险**
```
"你不需要一次性All in，可以分步走：
第1步：业余接几个小单，验证市场需求
第2步：如果顺利，逐步增加投入
第3步：当收入稳定后，再考虑全职

这样即使失败，也不会损失太多。"
```

**策略3：寻找同类案例**
```
"你知道吗？很多成功的人一开始也觉得自己不够格。

比如：
- [案例A]：一开始只是业余爱好，后来成了全职
- [案例B]：被别人推着走，才发现自己真的有天赋
- [案例C]：尝试了很多次才成功

你不是第一个有这种感受的人，也不会是最后一个。"
```

## 总结

好的问题设计应该：
- **具体化**：从具体场景切入，而非抽象概念
- **三角验证**：自我认知 + 外部反馈 + 实际成果
- **能量导向**：关注什么让用户充电，什么让用户耗电
- **动态追问**：根据回答灵活调整，不机械执行

追问的核心是：**帮助用户看见自己看不见的模式**。
