# 显式路径的 α 屈服交点与物理分段

## I — 方法论骨架 (Interpretation)

`α` 是当前总应变路径中从已提交状态走到首个屈服交点的弹性比例，定义域通常为 `[0,1]`。
先定义路径 `σ(α)=σ_n+De:(αΔε)` 及沿途的物理可容许域，再评价屈服函数 `f(α)`。
普通凸路径可从 `[0,1]` 建立括区；压力相关圆锥模型在 `p<0`、双穿越或数学延拓时要先按拓扑缩成 `[β,1]` 或 `[0,γ]`。
求根器的核心契约不是算法名字，而是区间有界、端点关系可验证、每次迭代保持括区不变量。
若路径上有多个根，应选择从 `α=0` 沿加载方向遇到的第一个物理可接受根，而不是任意残差最小点。
交点接受必须同时满足残差尺度、区间/步长尺度、物理域和有限数检查。
接受后只以 `αΔε` 更新弹性段；剩余 `(1-α)Δε` 才交给塑性子步积分。
若不能构造可信括区或在预算内求根，应回滚并进入失败升级，绝不猜测一个 `α` 继续计算。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 弹性试探点在屈服面外，需要从当前增量中定位首次屈服比例。
2. 压力相关模型在 `p≈0`、尖点或非凸路径附近出现多个交点、错误弹性判定或 `α` 越界。
3. 区间求根残差变小，但求得的交点不是加载路径遇到的第一个物理根。
4. 正在审查 `INTCHC`、`PEGSUS`、bisection、bracketing 或 elastic fraction 代码。

### 语言信号 (用户的话里出现这些就应激活)

- “怎么求纯弹性比例 α / elastic fraction alpha”
- “yield intersection / first yield crossing”
- “二分法、Pegasus、括区为什么不收敛 / bracketed root failure”
- “p<0 后还判断为弹性 / crossed the cone apex”
- “路径上有两个根应该取哪个 / multiple yield roots”

### 与相邻 skill 的区分

- 与 `explicit-adaptive-substepping`：本 skill 只定位弹性段终点；后者从交点之后对剩余路径控制局部 `DT`、误差和接受/拒绝。
- 与 `explicit-yield-drift-correction`：本 skill 找加载路径的首次交点；后者修复已积分塑性子步终点的屈服漂移。
- 与 `umat-failure-cutback-protocol`：本 skill 可报告交点搜索失败；后者负责回滚、失败预算和向 Abaqus 请求全局重算。
- 与隐式 return mapping：本 skill 求路径分数 `α`，不是联立一致性条件求塑性乘子 `Δλ`。

## E — 可执行步骤 (Execution)

1. **冻结已提交状态并定义 α 路径**
   - 保存 `σ_n`、全部状态变量和 `Δε`，定义 `α∈[0,1]` 上的弹性试探状态及 `f(α)`。
   - 完成标准：`α=0` 精确复现已提交状态，`α=1` 精确复现完整弹性试探；所有量单位和符号约定明确。
   - 判停路径：任一端点出现 NaN/Inf、材料参数非法或路径公式未定义时，不进入求根，回滚并报告域错误。

2. **先做物理域与路径拓扑分类**
   - 对模型要求的 `p`、不变量、加载方向和尖点条件逐项检查；只在压力相关圆锥模型的理论支持下计算 `β/γ`。
   - 完成标准：记录所选分支、推导依据和候选区间；区间满足 `0≤a<b≤1` 且不穿越禁止的数学延拓区。
   - 判停路径：无法证明候选区间位于物理域内时，标记“无可信括区”，不得用 `[0,1]` 兜底伪造成功。

3. **建立并验证括区不变量**
   - 计算 `f(a)`、`f(b)`；先处理端点已满足容差的情形，否则要求连续路径上的端点异号或模型给出的等价夹持条件。
   - 完成标准：日志保存 `a,b,f(a),f(b)`，并明确哪个端点代表面内/面外；每次迭代后该关系仍成立。
   - 判停路径：无符号变化且无理论支持的切触判据时，停止为“未括住根”，不能启动无界迭代。

4. **选择首个物理交点候选**
   - 若拓扑产生多个括区，按加载方向从小到大排序，逐个验证，取首个满足物理域的括区。
   - 完成标准：任何被跳过的更小 `α` 区间都有不可接受的明确理由，而不是因初值或迭代偶然性被忽略。

5. **执行有界求根并双尺度验收**
   - 使用二分或保持括区的加速法；每步重新评价状态、残差和有限数。
   - 完成标准：同时满足尺度化 `|f(α)|≤tol_f`、区间宽度或 `|Δα|≤tol_α`，且 `α` 位于物理区间。`10^-6` 只能作为示例起点，需按应力/屈服函数尺度重定标。
   - 判停路径：达到迭代上限、区间停滞、残差不连续或端点关系丢失时，恢复快照并向失败协议返回结构化错误。

6. **验证交点两侧和“第一个”属性**
   - 在不跨越数值尺度的小邻域检查加载前侧未屈服、后侧进入塑性或满足模型规定的方向条件。
   - 完成标准：根的残差、方向、物理域和首交属性均通过；若为切触根，须有模型专用判据及独立测试。

7. **原子拆分并交接剩余路径**
   - 以 `αΔε` 更新弹性应力，塑性内部变量保持旧值；把 `(1-α)Δε` 连同一致快照交给局部子步器。
   - 完成标准：两段应变精确相加为原 `Δε`，无重复积分或漏积分，且只有验收后的状态可以提交。

## B — 边界 (Boundary)

### 五个控制量必须隔离

- `α`：当前总应变路径的弹性段比例，通常无量纲且在 `[0,1]`；它不是硬化变量。
- 局部 `DT`：UMAT 内对子路径的归一化步长，累计局部参数 `T` 通常从 0 走到 1；它不是 Abaqus 的 `DTIME`。
- `Δλ`：塑性一致性/流动更新中的乘子；它由塑性积分算法定义，不能拿 `α` 代替。
- `PNEWDT`：UMAT 返回给 Abaqus 的下一全局增量比例建议；它不定位屈服交点，也不是局部 `DT`。
- `η_emb`：嵌入式两种近似解之差形成的局部误差指标（某些实现汇总为 `RTOL`）；它不是 Tsai-Wu 失效指数 `e`，也不是屈服残差 `f(α)`。

### 不要在以下情况使用此 skill

- 已知整个增量都在塑性段，只需控制局部积分误差：用自适应子步。
- 塑性子步已完成，只是终点偏离屈服面：用漂移修正。
- 采用隐式返回映射并需求解 `Δλ` 与内部变量的一致性方程：使用相应隐式积分方法。
- 屈服面或材料物理域尚未定义清楚：先做模型域审计，不能靠求根器补齐理论。

## 相关 skills

- **depends-on**: 无——本 skill 可在已声明应力表示和屈服函数后独立处理路径首交点。
- **contrasts-with**: `cpa-implicit-return-mapping`——本 skill 求加载路径首交点比例 `α`；后者求塑性一致性乘子 `Δλ`。
- **composes-with**: `explicit-adaptive-substepping`——首交点确定后，对剩余路径做自适应积分；`umat-update-mechanism-router`——当 `α`、`Δλ/Δγ` 与失效指数混淆时，先由路由器确认进入显式交点分支。
