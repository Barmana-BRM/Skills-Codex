# 阿勒泰写作法

受李娟散文启发的写作方法,核心理念是:满怀热忱地生活,忠实地记录,让笔成为生命经验的诚实回应。

## 核心原则(必读)

1. **真实优先** - 写亲眼所见,不编造不美化
2. **具体细节** - 用名词替代形容词,用细节替代概括
3. **感官体验** - 调动视觉、听觉、触觉、嗅觉、味觉
4. **克制表达** - 情感藏在故事里,不直接喊出来
5. **平凡即素材** - 日常生活就是最好的写作来源

## 使用场景

**创作新文章:**
1. 确认写作主题和素材
2. 运用48条心法中相关原则
3. 写完后用心法检查和改进

**改进已有文章:**
1. 通读全文,标记抽象、空泛之处
2. 对照心法逐段改进
3. 朗读检验是否自然流畅

**写作指导:**
1. 了解用户的写作困境
2. 推荐相关的心法原则
3. 给出具体改进示例

## 快速参考:常用心法

### 让文字更具体

- **原则8:** 把"美丽"换成"像刚拆封的蜡笔","悲伤"换成"空了的酱油瓶"
- **原则10:** 写妈妈,就写她系围裙时打的那个死结
- **原则19:** 写"他笑了",不如写"他眼角的皱纹挤在一起"

### 调动感官

- **原则5:** 去闻,去听,去摸。文字有温度,要写出来
- **原则13:** 写太阳,就写它怎么把晾着的被子晒出棉花糖的味道
- **原则37:** 写雨声,写它在铁皮屋顶、在芭蕉叶上、在池塘里的不同声音

### 捕捉细节

- **原则15:** 那个卖菜阿姨多找了你五块钱,你犹豫的一瞬间,就是好文章的开头
- **原则22:** 写吵架,就写那句到了嘴边又咽回去的、最伤人的话
- **原则30:** 写等待,就写你把手机握亮又关掉,反反复复的那十分钟

### 写作态度

- **原则2:** 别编。你亲眼看到云是灰的,就别写成彩的
- **原则3:** 坐下来,先写。写完了再想标题,别让想法溜走
- **原则35:** 别怕平淡。生活里没那么多惊天动地,写好一碗白米饭的滋味,才是真本事

## 工作流程

### 流程1:创作新文章

1. **选择素材**
   - 优先选择亲身经历的真实事件
   - 日常小事比宏大叙事更适合
   - 有具体时间、地点、人物的场景

2. **起草内容**
   - 坐下来直接写,不要先想标题(原则3)
   - 写完一段就站起来休息(原则6)
   - 把最想说的话藏在故事后面(原则4)

3. **添加感官细节**
   - 检查是否调动了多种感官(原则5)
   - 把形容词换成具体名词(原则8)
   - 写出声音、气味、触感的变化(原则25,37)

4. **朗读检验**
   - 读出声来,磕巴的地方需要修改(原则9)
   - 检查长短句是否交错(原则27)
   - 删掉"真聪明"但不真诚的句子(原则11)

5. **延迟发表**
   - 写完别急着发,放三天再看(原则29)
   - 舍得删掉不必要的段落(原则39)

### 流程2:改进已有文章

1. **通读标记**
   - 标记抽象的形容词:"美丽""悲伤""温暖"
   - 标记空泛的概括:"很开心""非常难过"
   - 标记陈词滥调:"狂风大作""人山人海"

2. **逐项改进**
   - 把形容词改成名词或具体场景
   - 把概括改成具体动作和细节
   - 把成语改成自己的观察

3. **增加层次**
   - 补充感官细节(看、听、闻、触、尝)
   - 添加身体记忆(原则31,45)
   - 写出过程和变化(原则25)

4. **检查真实性**
   - 确认每个细节都是真实或合理的
   - 删除为了"文学性"而编造的内容
   - 保持诚实的观察者视角(原则16)

### 流程3:写作诊断

当用户说"写不好""没感觉""太平淡"时:

1. **读用户的文章或片段**
2. **诊断问题**
   - 是否过于抽象? → 推荐原则8,10,19
   - 是否缺少感官? → 推荐原则5,13,37
   - 是否直白说教? → 推荐原则4,22
   - 是否用词陈旧? → 推荐原则32
3. **给出改进示例** - 参考 references/writing-examples.md
4. **推荐练习方向**

**按主题查找心法:**

- **基础态度** (1-6): 准备笔记本、真实第一、先写再改、克制表达、感官体验、适时休息
- **细节观察** (7-17): 观察生活、名词替换、朗读检验、具体细节、真诚表达、原创素材、感官描写、日常素材、捕捉瞬间、记录者心态、动作细节
- **个人素材** (18-23): 个人经历、具体替换、允许失败、记忆深处、冲突细节、名词力量
- **阅读与变化** (24-29): 扩展阅读、过程变化、暴露脆弱、句式变化、第一印象、延迟发表
- **深度与真实** (30-40): 重复动作、身体记忆、避免陈词、生活现场、身体细节、珍惜平凡、回顾过去、声音变化、觉察瞬间、敢于删减、沉默的声音
- **成长与坚持** (41-48): 观察细节、写印象、写挫折、量变质变、身体痕迹、具体时刻、共同经验、生活为师

## 使用技巧

1. **不要一次用全部48条** - 每次关注3-5条相关的即可
2. **从最明显的问题开始** - 先改抽象词,再加感官,最后调整结构
3. **保持作者的声音** - 改进细节但不改变原作者的语气和风格
4. **结合实例说明** - 改进时给出具体的前后对比
5. **鼓励观察生活** - 写作的根本在于生活,不在技巧

## 示例:改进一段文字

**原文:**
> 今天天气真好,我心情也很愉快。走在路上看到美丽的风景,感觉生活真美好。

**问题诊断:**
- 过于抽象:"天气真好""很愉快""美丽的风景"
- 缺少感官细节
- 直接说"感觉美好"而非展示

**改进方向(运用原则5,8,13,46):**
> 下午三点的阳光斜着照在人行道上,我的影子拉得很长。路过面包店时,黄油的香味飘出来,混着街边桂花树的甜味。我放慢脚步,看着光斑在树叶间跳动。

**改进说明:**
- 具体时间(下午三点)和具体场景(人行道、影子)
- 感官细节(黄油香味、桂花甜味)
- 用动作展示心情(放慢脚步、看光斑)而非说"愉快"

## 常见误区

1. **过度修饰** - 别把简单的事写复杂,保持本色
2. **刻意诗意** - 不要为了"文学"而失去真实
3. **堆砌技巧** - 自然流露好过刻意展示
4. **忽视朗读** - 不读出来就发现不了别扭之处
5. **急于求成** - 好文章需要时间沉淀(原则29)

## 输出格式

**创作新文章时:**
- 直接输出改进后的文章
- 在文末简要说明运用了哪些心法

**改进文章时:**
- 先指出主要问题
- 逐段给出改进建议和示例
- 总结运用的心法

**写作指导时:**
- 诊断问题类型
- 推荐相关心法(3-5条)
- 给出具体练习方向
