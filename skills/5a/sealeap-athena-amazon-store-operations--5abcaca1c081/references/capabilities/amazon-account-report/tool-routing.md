# 工具选择与能力边界

先检查当前 Agent 暴露的工具、已安装连接和同口径本地材料。只选择本任务需要的能力；下面是已核对的路由，执行参数以当前 schema 或 CLI 帮助为准。身份、市场、配额、计费与实际数据响应在执行时另行确认。

## 官方账户能力

本任务处理 Amazon 自有账户数据。使用该平台已授权的官方 API / MCP / CLI，或用户提供的正式后台导出。市场情报数据源不能代替账户授权、订单、付款或写权限。

若环境已安装 `ecomi-amazon-sp`，先读取其 Skill 和 `spapi.py --help`，按 store 与 sandbox/prod 选择连接；扩展 API 操作必须先核对当前 SP-API schema、HTTP 方法和权限。现有工具未提供相应操作时交付草案并列连接缺口。

API 参考入口：[Amazon SP-API 文档](https://developer-docs.amazon.com/sp-api/)。

对照官方 schema 填写参数、分页、版本和签名；秘密只从凭证管理器或受保护环境注入。不要把令牌放入 URL、提示词、日志或 Git。未提供账户的任务不主动启动 OAuth 或切换浏览器账户。

## 本任务不能被替换掉的语义

报告任务成功不等于下载文件完整；只读任务不新建远程报告；多分片必须对账。

接入检查只代表工具存在。新任务中必须根据真实返回记录成功、失败、空结果、字段缺失与数据时间；不得将本地格式校验标成在线业务验证。
