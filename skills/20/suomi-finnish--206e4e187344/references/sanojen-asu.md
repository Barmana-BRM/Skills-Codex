# Sanojen asu ja sananvalinta

Täydentää `SKILL.md`:n lukua 9 (tekoälyn tyypilliset virheet). Tässä käsitellään sanastotason ongelmat: vierassanojen asu, anglismit ja ne tapaukset, joissa kaksi muotoa on rinnakkain hyväksyttyjä.

---

## 1. Vierassanojen asu

Vierasperäiset sanat mukautetaan suomen kirjoitusjärjestelmään. Kirjaimet c, q, w, x ja z korvataan yleensä:

```
kemia       (ei chemia)
kvantti     (ei quantti)
sinkki      (ei zinkki)
kaaos       (ei chaos)
```

Poikkeuksena sitaattilainat ja erisnimet säilyttävät lähtökielen asun.

**Älä päättele kaksoiskonsonantteja englannin perusteella.** Suomen asu ei seuraa englantia, ja kielimalli arvaa tässä usein väärin. Ainoa luotettava tapa on tarkistaa sana [Kielitoimiston sanakirjasta](https://www.kielitoimistonsanakirja.fi/) — siellä on sekä kirjoitusasu että taivutus.

---

## 2. Anglismit sanastotasolla

Kielimalli suosii englannista lainattua sanastoa, koska sen opetusdata on englantipainotteista. Alla yleisimmät ja niiden suomenkieliset vastineet.

### 2.1 Turhat lainaverbit

| Vältä | Käytä |
|---|---|
| implementoida | toteuttaa, ottaa käyttöön |
| adressoida | käsitellä, puuttua johonkin |
| eskaloida | viedä eteenpäin, nostaa esiin |
| allokoida | kohdentaa, jakaa |
| identifioida | tunnistaa |
| validoida | vahvistaa, todentaa |
| initioida | käynnistää, aloittaa |
| kommunikoida jotakin | kertoa, viestiä |

### 2.2 Käännöslainat ja fraasit

| Vältä | Käytä |
|---|---|
| ajaa kasvua | kasvattaa, lisätä |
| tuoda pöytään | tarjota, antaa |
| syväsukellus aiheeseen | perusteellinen tarkastelu |
| avainoppimiset | keskeiset havainnot |
| seuraavat askeleet | jatkotoimet |
| ottaa askeleita kohti | edetä, pyrkiä |
| kun on kyse X:stä | X:ssä, X:n osalta |
| muutakin kuin vain | enemmän kuin |

### 2.3 Tyhjä aloitus- ja lopetusretoriikka

Nämä ovat kielimallin tunnusmerkkejä. Poista ne kokonaan, älä korvaa:

```
Nykypäivän nopeatempoisessa maailmassa…
Ei ole yllätys, että…
Sukelletaanpa syvemmälle aiheeseen.
Tässä artikkelissa käymme läpi…
Yhteenvetona voidaan todeta, että…
Toivottavasti tästä on apua!
```

Sama koskee rakennetta *ei ainoastaan… vaan myös*, jota kielimalli käyttää moninkertaisesti tavallista kirjoittajaa useammin.

### 2.4 Vakiintuneet lainat, joita EI tarvitse korjata

Kaikki lainasanat eivät ole anglismeja. Nämä ovat vakiintuneita, eikä niitä pidä väkisin suomentaa:

```
analyysi, data, projekti, prosessi, resurssi, strategia,
optimoida, konteksti, dokumentti, standardi
```

## 3. Älä ylikorjaa: rinnakkain hyväksytyt muodot

Kielimalli korjaa toisinaan oikeita muotoja vanhentuneiden sääntöjen perusteella. Näissä **molemmat muodot ovat yleiskieltä**, eikä kumpikaan ole virhe:

| Muodot | Päätös |
|---|---|
| alkaa tehdä ~ alkaa tekemään | Suomen kielen lautakunta 2014 |
| evankelisluterilainen ~ evankelis-luterilainen | Suomen kielen lautakunta 2016 |
| haltia ~ haltija (satuolennosta) | Suomen kielen lautakunta 2013 |
| asiakkaiden ~ asiakkaitten | vakiintunut rinnakkaisuus |
| vaatimusten ~ vaatimuksien | vakiintunut rinnakkaisuus |

Lähde: [Suomen kielen lautakunnan suosituksia](https://kotus.fi/kotus/lausunnot-suositukset-ja-kannanotot/suomen-kielen-lautakunnan-suosituksia-ja-kannanottoja/suomen-kielen-lautakunnan-suosituksia/).

Periaate: kun kaksi muotoa on rinnakkain sallittuja, valitse toinen ja käytä sitä johdonmukaisesti koko tekstissä. Älä merkitse toista virheeksi.

---

## 4. Yleiskieli vs. puhekieli

Asiatekstissä käytetään yleiskieltä. Yleisimmät puhekielisyydet, jotka kielimalli päästää läpi:

| Puhekieli | Yleiskieli |
|---|---|
| mun, sun, meidän juttu | minun, sinun, meidän asiamme |
| ne tulee | ne tulevat |
| tää, toi | tämä, tuo |
| tsekata | tarkistaa |
| kato | katso |

Omistusliite kuuluu yleiskieleen: *taloni*, ei *mun talo*.

Huomaa kuitenkin, että markkinointitekstissä ja verkkosisällössä puhuttelu voi olla tarkoituksellisen vapaata. Arvioi tyylilaji ennen korjaamista.

## 5. Kirjoitusasun tarkistaminen

Epäselvässä tapauksessa järjestys on:

1. [Kielitoimiston sanakirja](https://www.kielitoimistonsanakirja.fi/) — kirjoitusasu, taivutus, rektio
2. [Kielitoimiston ohjepankki](https://kielitoimistonohjepankki.fi/) — säännöt ja perustelut
3. [Iso suomen kielioppi](https://kaino.kotus.fi/visk/etusivu.php) — kuvaileva kielioppi

Älä arvaa kirjoitusasua. Jos sanaa ei löydy sanakirjasta, harkitse toista sanaa.
