# 工具选择与能力边界

先检查当前 Agent 暴露的工具、已安装连接和同口径本地材料。只选择本任务需要的能力；下面是已核对的路由，执行参数以当前 schema 或 CLI 帮助为准。身份、市场、配额、计费与实际数据响应在执行时另行确认。

## 已有 CLI 直连

先使用 `command -v ecomi` 定位；若不在 PATH，从已配置项目的 `.venv/bin/ecomi` 定位，不自动重装或读取凭证内容。

先运行 `ecomi query --help` 核对选项。工具安装和帮助可用只证明接口存在，不证明已登录、有配额或能访问目标数据。

使用当前 Ecomi 的 `query --provider sif --endpoint <方法名> --asin <ASIN> --marketplace <站点> --raw`。仅使用自己已授权的账户；原始返回错误或权限不足时停止数据推断，不把异常归一化成空列表。

此技能的 SIF 方法已在本地 provider 中确认。不要把不支持的“关键词级总览”方法名硬传给 `query`；当前范围按下表方法和实际返回为准。

- `asin_keyword_list`：按当前 endpoint/method schema 填写业务输入。

已授权调用仍需尊重样本和费用范围。只在当前工具确实覆盖相同市场、实体、时间与指标时换用其他提供方；不能保留原指标名称却悄悄替换成含义不同的数据。

## 本任务不能被替换掉的语义

必须读取原始响应成功状态；登录过期不能当空结果；不能用词表推算真实订单。

接入检查只代表工具存在。新任务中必须根据真实返回记录成功、失败、空结果、字段缺失与数据时间；不得将本地格式校验标成在线业务验证。
