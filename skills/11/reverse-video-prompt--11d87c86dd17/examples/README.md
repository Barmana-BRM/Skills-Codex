# Examples

这个目录用于放可公开分享的案例说明。

建议只提交：

- 打码或授权截图
- contact sheet
- 时间点对比说明
- 原提示词和新版提示词
- learning card

不要提交：

- 无授权原始视频
- 客户素材
- 包含隐私信息的人物素材
- 本地绝对路径

推荐案例结构：

```text
examples/
└── window-film-tool-drift/
    ├── README.md
    ├── contact-sheet-reference.jpg
    ├── contact-sheet-generated.jpg
    └── learning-card.yml
```
