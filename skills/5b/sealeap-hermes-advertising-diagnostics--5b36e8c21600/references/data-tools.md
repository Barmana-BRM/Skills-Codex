# 数据工具路由

## 选择顺序与能力边界

优先复用与本任务平台、站点、日期和指标定义一致的本地报告。需要外部数据时沿用工作区既有授权与提供商路由；直接选择具备目标能力的连接器，不依赖某个聚合平台安装器。

| 需求 | 可选通路 | 不可替代的边界 |
|---|---|---|
| 自家销售、库存、Listing、查询绩效 | 已授权 SP-API、后台报告或 ERP 导出 | 市场估算不能填补自家真实经营数据 |
| 自家广告表现 | 已授权 Ads API / 广告导出 | SIF 或竞品广告位观察不能提供自家真实 CPC/CVR |
| 市场/ASIN/关键词 | 卖家精灵已有连接器、Sorftime、Jungle Scout 或导出 | 确认站点、时间、父子体、指标定义和配额 |
| 关键词反查/卡位/流量趋势 | 已授权 SIF、卖家精灵或 Sorftime | 卡位统计不等于销量，也不是真实广告支出 |
| 跨平台或供应报价 | 覆盖目标平台的 Sorftime/其他已授权工具、供应商报价 | 统一规格、包数与 Incoterm；网页展示价不是采购合同 |
| 页面和评论观察 | 当前浏览器能力或授权导出 | 记录样本、分页和时间；登录失败不绕过访问控制 |

## 发现与调用

1. 检查现有工具目录、CLI `--help` 和连接状态；不要在结果中打印密钥、Cookie 或完整登录配置。
2. 查看实际工具 schema 和对应提供商的参数定义。工具缺失时用授权导出或标记 UNAVAILABLE，不编造 API、URL、参数或成功响应。
3. 形成调用计划：对象、站点、窗口、页数、参数、费用上限和输出位置。沿用已有费用授权；新费用或超出范围才确认。`--help` 通过不代表在线鉴权或配额可用。
4. 限定取数，检查原始业务状态码、分页终止与记录数。401/403、配额耗尽或业务失败应停止并说明原因，不能把空列表视为零需求。
5. 保存业务数据源和采集时间，输出中保留其真实性。数据采集授权不自动授权店铺写入、外部同步或批量模型调用。

## 已有 ecomi 环境的可选入口

这些帮助命令已在本地安装版本核验，但 ecomi 是可选适配器。调用前定位当前安装位置；不要把个人电脑的绝对路径写入可分发 Skill。

```bash
ecomi --help
ecomi query --help
ecomi ssopen --help
ecomi sorftime --help
```

在当前环境已有授权配置时，用对应 provider 的工具列表/schema 确认能力。`ssopen` 与登录态 `sellersprite` 是不同通路，不能互换鉴权或假设配额共享；遵守目标工作区既有选择规则。SIF 同样按已发现的 schema/本地 provider 方法调用。

部分列表发现会访问外部服务或写缓存；严格只读任务只用现有 schema/帮助和已有数据。此集合没有为第三方 CLI 虚构 `--dry-run` 或 `--allow-cost` 开关。完整缺失时交付待执行取数计划。
