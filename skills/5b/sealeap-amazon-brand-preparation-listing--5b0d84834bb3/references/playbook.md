# 筹备阶段页面制作手册

## 从人口统计转向真实任务

材料中的投影幕布案例先根据年龄与收入推断“户外聚会看足球”，随后由真实评论与场景分析修正为家庭在后院/客厅看电影。可复用的是校准方法，不是年龄、收入或场景占比。

按 `角色 / 使用地点 / 使用时刻 / 任务 / 预期收益 / 限制 / 原始证据位置` 归类。第三方画像是代理证据；不同维度占比不得相加，也不能当成当前品牌总体画像。没有 ABA 人口统计权限时列缺口并使用可合法取得的聚合证据。

## 页面表达顺序

1. 用产品事实解释最重要的购买问题。
2. 用真实场景说明这些事实如何帮助消费者。
3. 让标题、五点、图片、视频、A+ 的信息互相一致，各自承担清楚的任务。
4. 品牌信息服务于消费者理解；避免把每个位置都堆品牌名或未经证明的地位声明。

## AI 输入模板

```text
目标站点与语言：
产品事实和不能改变的规格：
已验证消费者任务及证据：
品牌语气和当前平台内容规范：
关键词及优先级：
原有文案和可参考的表达风格：
需要输出的字段、字数或当前字段限制：

请只使用已提供且可证明的事实。对缺失信息列问题。
输出本地语言草稿，逐条说明关键词位置、事实来源和修改原因。
最后检查重复、单位、兼容性、场景与没有依据的承诺。
```

参考竞品只用于理解消费者问题和表达方式，不复制其文案、图片或未验证的卖点。图像生成不得改造商品规格、数量或性能。

## A+ 与创意简报

按产品特点、使用场景、安装/使用说明等实际需要选择模块。每个模块给出主信息、产品证据、图片任务、文案草稿、移动端检查及素材权利来源。是否具备高级 A+ 或生成工具以当前账号为准。

## 本地化审校

AI 自检可发现明显问题，但不能当成母语审校完成。对关键功能、承诺、警告、尺码和文化语境保留人工核验任务。回译用于发现信息漂移，不作为唯一质量证明。

## 效果验证

确认实验资格和内容审核后，再设置基线、主变量、主指标、观察窗口与停止条件。分清页面访问、会话转化与广告订单 CVR，避免混用。结果不成熟时报告进行中，不宣告改版成功。
