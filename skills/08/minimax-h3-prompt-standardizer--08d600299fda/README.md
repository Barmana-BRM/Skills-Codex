# MiniMax H3 Indicator

A Cordex Skill for White. Inputs, whether they are a sentence, a prefix, an image idea, or a full story and script, can be compiled into standard video alerts that can be used directly for Mini Max H3.

What can you handle

- Extension of one sentence to H3.
- Collapse, retrenchment and error.
- Story or script production program
- Story, action, ads, Vlog, reality and 2D animation.
- Single graphs, multigraphs, front-end frames and role consistency references
- Design of white, mouth, environment, motion and music

# Use example

```text
使用 $minimax-h3-prompt-standardizer：一个女孩在雨夜车站等人，8秒，16:9。
```

```text
使用 $minimax-h3-prompt-standardizer，把下面这段故事拆成适合 H3 分段生成的规范提示词：……
```

Default to give priority to the direct output of a copyable Chinese hint; a short question will be asked only if there is a real lack of information that will change the outcome.
