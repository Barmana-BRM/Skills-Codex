# Amazon 竞品快照与变化监控执行手册

## 核验与持久化

搜索候选不能直接成为已核验竞品。详情返回 ASIN 必须匹配，规格和购买任务需有人工判断证据；“数据源已核验”不代表前台当前可购买。

价格需有详情或明确历史来源，缺失不回填为零。同父变体、配件、耗材与套装应独立标注而非机械当成竞品。每次采集保留 collected_at、data_period、currency、evidence_id 和字段证据标签。

SQLite 记录追加保存；相同快照重复导入幂等，键相同但内容不同时报冲突，不覆写历史。导入前验证全批数据，任何格式错误都不能留下半批记录。每条快照保留真实或合成的 data_mode，不能混作当前真实市场。

## 变化判读

只对相同站点、商品、来源、字段、数据模式和计量单位比较。前后缺失、未核验或币种不一致时不输出数值差额。历史期指标不得与当前周期直接算差；可比性不足时同时展示原值与缺口。

## 输出

报告含候选状态、价格与标题前后值、采集时间、来源和原始证据引用。建议注明目标位置、当前值、建议值、支持 ASIN/关键词、优先级和未证实假设。

## 运行范围

随包脚本为离线导入、SQLite 和 HTML 报告工具；不包含特定机器上的服务、登录会话或自动取数任务。需要后台常驻时，根据当前连接器能力实现独立 Worker；会话内 MCP 可用不证明浏览器关闭后还能调度。采集失败保留失败状态，不自动切换成合成市场数据。
