# 人工回传后的公开页检查

复用同一 G。用户回传公开 URL 和“接受/需修复”结论后，对照已交付版本检查标题、正文、真实链接、图片、可核验 Alt/图注、CTA、披露和语言字符是否在发布过程中丢失或变形。只有 URL 时不要推定人工接受；只问必要缺项。

标题层级只以公开读者页的渲染视觉判断，不能用编辑器 HTML/DOM、源码或 Feed 证明 H1/H2/H3 合格。看不到的 Alt、页面内容或层级记为未核验，不能为了完成而猜测通过。

不重做研究、关键词策略、全文编辑或质量审稿，不重启 W/R。传递错误给人工一份合并修复提示，修复后只复核相关项。只有用户明确要求改本地稿时才回该文原质量路线。

一条进度记录足够：文章 ID、URL、人工结论、公开检查结论、证据入口及真正剩余问题。正常通过不抄全文、不生成全绿报告；未取得证据不能计完成。人工接受且公开检查通过才完成本篇，存在明确平台限制时说明范围，不外推为通用能力。

旧 campaign.json 项目按原回执/快照结构存证，详见[旧 G 接口](legacy-gate.md)，但不因此重复写审。
