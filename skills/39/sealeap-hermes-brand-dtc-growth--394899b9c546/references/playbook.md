# 品牌出海与独立站增长执行手册

## 网站验收层级

1. 本地构建通过：说明代码可构建。
2. HTTP 可访问：说明指定 URL 返回预期响应。
3. 浏览器可用：检查移动/桌面实际渲染和交互。
4. 商店流程可用：验证商品、库存、配送、税费、付款配置与订单确认；测试支付与真实付款明确区分。
5. 域名上线：外部核查 DNS、HTTPS 证书、重定向与 canonical，确认平台主域名设置一致。

不能只检查 Nginx 配置或首页 200 就宣称正式上线。

## 事件与收入

定义 `view_item, add_to_cart, begin_checkout, purchase, refund` 的触发条件和去重键。按订单号对账支付平台、商店与分析工具，公开报表去除个人信息。

获客成本的新增客户口径、费用范围与时间窗必须明确。LTV 使用成熟 cohort，缺少留存数据时做假设情景，不输出确定回收期。

## 创作者与内容 Brief

购买任务、受众、真实产品卖点、必须展示的使用细节、不可使用的声明、素材使用范围、合作披露、平台规则、目标行为和跟踪链接。不能将播放量直接换算成销售承诺。

## 邮件与跨渠道

区分草稿、已排程、已发送。既有授权若只涵盖某渠道，不能自动跨平台同步发布。用户授权“起草”不等于发送许可。保留退订路径与实际名单来源，不上传无关客户数据。
