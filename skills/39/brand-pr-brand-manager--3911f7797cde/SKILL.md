# 品牌管理助手

## 核心工作流程

### 1. 品牌诊断与定位

**品牌现状分析框架：**
```
品牌基础信息
├── 品牌名称/标语/视觉标识
├── 品牌历史与发展阶段
├── 目标受众画像
└── 当前市场认知

竞争格局分析
├── 直接竞争者品牌定位
├── 间接竞争者差异点
└── 市场空白机会

品牌资产盘点
├── 品牌知名度
├── 品牌联想
├── 感知质量
└── 品牌忠诚度
```

**定位策略选择：**
- **品类领导者**：占据品类第一心智（适合市场领先者）
- **差异化挑战者**：找到独特价值主张（适合后来者）
- **细分专家**：聚焦垂直细分市场（适合资源有限者）
- **重新定义者**：创造新品类或重构认知（适合颠覆者）

### 2. 品牌架构设计

**架构模式选择：**

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| 单一品牌 | 所有产品共用一个品牌 | 产品关联度高、资源集中 |
| 主副品牌 | 主品牌+产品系列名 | 需要品类延伸但保持关联 |
| 背书品牌 | 子品牌+母公司背书 | 进入新市场但借助母品牌信任 |
| 独立品牌 | 完全独立的品牌组合 | 面向差异化市场、避免关联风险 |

### 3. 品牌故事构建

**品牌叙事框架（3C模型）：**

```
Context（背景）
└── 为什么这个品牌存在？解决什么问题？

Character（角色）
├── 品牌人格：如果品牌是人，TA是什么样的？
├── 创始人故事：创立初心与愿景
└── 用户故事：典型用户的转变历程

Conflict & Resolution（冲突与解决）
├── 用户面临的挑战
├── 品牌如何独特地解决这个挑战
└── 用户获得的转变结果
```

**品牌核心信息层级：**
1. **品牌使命**（Why）：品牌存在的根本意义
2. **品牌愿景**（Where）：品牌追求的未来图景
3. **品牌价值观**（How）：品牌坚守的行为准则
4. **品牌承诺**（What）：品牌对用户的核心承诺
5. **品牌个性**（Who）：品牌的人格化特征

### 4. 品牌一致性审计

**审计维度清单：**

```
视觉一致性
├── Logo使用规范（尺寸/间距/禁用变体）
├── 色彩系统（主色/辅色/中性色应用）
├── 字体系统（标题/正文/辅助字体）
├── 图像风格（摄影风格/插画风格）
└── 版式规范（网格/留白/层级）

语言一致性
├── 品牌语气（正式/友好/专业/活泼）
├── 核心术语表（统一用词）
├── 标语与口号
└── 文案风格指南

体验一致性
├── 线上触点（官网/App/社交媒体）
├── 线下触点（门店/包装/印刷品）
├── 客服体验（话术/态度/解决方式）
└── 产品体验（开箱/使用/售后）
```

### 5. 品牌健康度评估

**评估指标体系：**

| 维度 | 关键指标 | 评估方法 |
|------|----------|----------|
| 知名度 | 品牌认知率、品牌回忆率 | 问卷调研 |
| 美誉度 | NPS、品牌好感度 | 用户反馈分析 |
| 忠诚度 | 复购率、推荐意愿 | 行为数据 |
| 关联度 | 品牌联想词、心智定位 | 语义分析 |
| 溢价力 | 相对竞品价格弹性 | 市场数据 |

**健康度诊断输出：**
```
品牌健康度报告
├── 总体健康评分（0-100）
├── 各维度得分与行业对比
├── 关键问题识别
├── 优先改进建议
└── 行动计划时间表
```

## 输出模板

### 品牌定位陈述模板
```
对于 [目标用户]，
[品牌名称] 是 [品类/框架] 中的
[差异化定位]，
因为 [支撑理由/独特能力]。
```

### 品牌审计报告结构
```
1. 执行摘要
2. 审计范围与方法
3. 品牌资产现状
4. 一致性评分（视觉/语言/体验）
5. 问题发现与影响分析
6. 改进建议优先级排序
7. 实施路线图
```

### 品牌策略建议结构
```
1. 现状诊断
2. 机会与挑战
3. 战略方向建议
4. 关键举措
5. 预期成果
6. 资源需求
7. 风险与应对
```

## 最佳实践

- **先诊断后处方**：充分了解品牌现状再给建议
- **用户视角优先**：所有策略以用户感知为出发点
- **一致性为王**：品牌价值在重复中积累
- **差异化聚焦**：宁可在一点上极致，不要处处平庸
- **长期主义**：品牌建设是马拉松，避免短期行为
