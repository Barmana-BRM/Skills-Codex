# 外链自动提交合并版 · 执行检查单

> 每站在最终动作前、结果判断后各检查一次，并在记录中写 `checklist PASS/FAIL`。任何未通过项都要写明原因；未修复前不得继续该站最终动作。

## A. 预检与入口识别

- [ ] 可达性：确认首页和当前入口可达；不可达时记录 `unavailable`，不反复打开。
- [ ] 正常入口：从导航、页脚、账户区域、站内搜索和真实链接/按钮发现当前入口。付费或合作页只标记为跳过，随后回首页继续寻找免费正常入口并核验重定向。
- [ ] 视觉兜底：仅当常规手段没有找到任何可验证入口时，才检查页面首、中、尾三段；视觉候选必须再核验真实控件或最终路由。
- [ ] 曝光类型：识别商家通道、资料页、目录、项目展示、免费广告、新闻稿、账号资料链接位和当前批次已授权的官方 Contact 邮件入口。
- [ ] 内容面分类：短贴、长文和无法分类的内容编辑器分别记录为 `short note — no action`、`long post — no action`、`unknown — no action`；均不得输入、预填、保存草稿、交人工、提交或发布。只有内容编辑器的站点记为 `ineligible`。
- [ ] 站内去重：实际触发固定查询集——规范网址（含尾部斜杠变体）、裸域名、品牌或产品拼写、标题词序/空格/连字符变体；检查后台、近期和分类列表。每个候选必须核验实际出站网址。
- [ ] 去重例外：仅在当前批次明确授权直接尝试时，才能使用 `not available — user-authorized direct attempt` 或 `inconclusive — user-authorized direct attempt`；记录缺口、证据和授权引用，且只允许一次最终提交。
- [ ] 身份和权限：确认当前批次对登录、注册、无费用营销订阅和官方 Contact 邮件的授权；付费、自动续费、强制互链、账号异常和强反自动化不在普通授权内。

## B. 填写、验证与交接

- [ ] 字段完整：仅填写已核实、如实且适用的资料。未知或不适用字段才可留空，并记录原因。
- [ ] 受控表单：填写后回读名称、描述、网址、类别和必填字段。刷新或切换方案后必须重新检查全部字段。
- [ ] 图片上传：确认上传完成、页面解锁或下一步可用后再继续；超时或失败时保留标签页转人工。
- [ ] 验证交接：无法自动完成验证时，预填所有适用字段、上传素材，并在已授权时勾选无费用营销订阅。保留原标签页、网址、目标标识和剩余动作；禁止留空表或关页。
- [ ] 官方 Contact 邮件：确认当前批次授权、已核验 Gmail 发件别名、官方收件来源和发送前去重。正文应真实、逐站相关，不得请求 dofollow、互链、排名承诺或内容发布；发送前回读 From、To、主题、正文、链接和空 CC/BCC。

## C. 最终动作与结果

- [ ] 失败即停：第一个明确页面或网络错误出现后停止该站该动作，记录证据；不得盲目重试。
- [ ] 一次最终动作：Submit、Publish 和 Gmail Send 只点击一次。动作前启动即时状态和网络响应捕获。
- [ ] 三类证据：确认状态或路由变化、原生正向回执、后台/邮箱/公开页等独立确认互相一致。点击、跳转、草稿、清空表单或泛化感谢页都不算成功。
- [ ] 结果不明：只读核验两到三轮。表单查当前页、后台、邮箱和公开页；邮件查撰写页或线程、Sent/All Mail、Drafts/Outbox。仍不明确时保留页面并记录结果不明，绝不重投或重发。
- [ ] 邮件状态：邮件已发送只能记 `email sent — awaiting reply`，不代表送达、回复、收录、外链或发布。

## D. 自动化与记录

- [ ] CDP 重试审议：记录错误和当前状态，提出至少两个可区分假设，先做最小只读判别。只有新证据且下一步实质变化时，才允许一次受控重试；最终动作零次重试。
- [ ] CU 复核：仅当前授权允许时，对 CDP 无法明确结论的站点做一次 CU 复核；不得借此绕过去重、验证码或一次最终动作规则。
- [ ] 标签页：清理无关旧标签页；保留人工交接页和结果不明页。不得为解决站点问题改动浏览器管理客户端或账号设置，除非另有当前授权。
- [ ] 公开记录：只保存别名和受控证据标识；不得写入密码、验证码、Cookie、会话标识、原始邮箱、电话或令牌化网址。完成后运行审计脚本并逐站交付。
