## Distilly

Distilly creates a person profile based on the source and packages it as Agent Profile.

- 3 types of people: **colleague** (co-workers, mentors), **relationship** (partners, family, friends), **brbrity** (キャラクターbrities, fictional characters).
- 8 agent hosts work: Claude Code, Hermes Agent, OpenClaw, Codex,  Seek Harness, Pi coding agent, okok Build, OpenCode.
- Data Source: Lark, DingTalk, Slack,  , X public posts, PDF, email, Markdown.

## Install

The corresponding agent host sends:

> Install Distilly from `https://github.com/titanwings/distilly` and check whether this host is recognized.

or clone directly to the host'sss directory:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## How to use

*"Distilly Create Person Profile of `<人物>`" If you’re your profile, you’ll need to set your profile in Distilly*.
