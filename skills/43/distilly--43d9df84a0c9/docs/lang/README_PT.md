## O que o Distilly faz

Distilly transforms source material (messages, documents, interviews, public sources) and its description into a source-based Person Profile, and packages it as Agent Skill.

- It's okay. Three types of person: **colleague** (colleagues, mentors), **relationship** (partners, family, friends) and **celebrity** (public figures, fictional characters).
- Works on eight agents hosts: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build and OpenCode.
- Sources: Lark, DingTalk, Slack, WeChat, public X posts, PDF, email, Markdown.

## Instalação

Em qualquer host de agentes compatível, envie:

> Install Distilly from `https://github.com/titanwings/distilly` and make sure this host finds it.

Ou clone você mesmo no diretório de Skills do seu host:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## Uso

Tell your agent: *"Use Distilly to create a `<pessoa>` Profile." For your own profile: *"Use Distilly to configure my profile."*
