# SPSS Workflow For Management And Social Science Research

## 1. Data Setup

- Keep one row per observation.
- Use stable variable names in English or pinyin.
- Keep labels in SPSS variable labels rather than only in Excel headers.
- Define missing values explicitly.
- Save raw data, cleaned data, and syntax separately.
- Never overwrite raw data.
- Record reverse-coded items.
- Record scale construction rules.
- Record exclusion criteria.
- Keep a data dictionary.

## 2. Common Survey Analyses

- Reliability analysis: Cronbach alpha and item-total correlation.
- Exploratory factor analysis: KMO, Bartlett, extraction, rotation.
- Descriptive statistics: mean, SD, min, max, skewness, kurtosis.
- Correlation matrix: Pearson or Spearman depending on measurement and distribution.
- Regression: hierarchical entry if theory requires staged controls.
- Mediation: prefer bootstrap confidence intervals.
- Moderation: center variables before interaction when helpful.
- Common method bias: do not rely on one Harman test only.

## 3. Common Experimental Analyses

- Randomization check.
- Manipulation check.
- T test or ANOVA for group differences.
- ANCOVA if pre-treatment covariates are theoretically justified.
- Effect sizes: Cohen d, eta squared, odds ratio where appropriate.
- Exclusion rules must be stated before seeing outcomes.

## 4. Reporting Rules

- Report N and missing-data handling.
- Report exact p-values when possible.
- Report confidence intervals for main effects.
- Use unstandardized coefficients for interpretation when units matter.
- Use standardized coefficients when comparing relative strength.
- Keep tables aligned with manuscript hypotheses.
- Do not claim causality unless design supports it.

## 5. Reviewer Risks

- Scale reliability is shown but construct validity is weak.
- EFA is used when CFA is required for mature scales.
- Mediation is cross-sectional but written as process evidence.
- Moderation is significant but not plotted or interpreted.
- Controls are added mechanically without theory.
- Missing values are silently listwise-deleted.
- PROCESS output is copied without explaining the model.
- Survey source and ethics are unclear.
- Common method bias is handled superficially.
- Tables do not match hypotheses.
