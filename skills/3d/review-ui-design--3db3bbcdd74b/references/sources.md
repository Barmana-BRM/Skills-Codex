## 1. 使用原则

- 只吸收可迁移的方法，不复制文章原文。
- 把“经验技巧”视为启发，把平台规范和 WCAG 数值视为可核验基准。
- 老文章中的固定尺寸、设备参数和趋势结论可能过时；使用时以当前平台规范为准。
- 60-30-10、三色限制、奇偶数字号、固定字阶/行高、固定栅格、固定圆角和投影公式等只可作为诊断提示，不能当成普遍硬规则。
- “高级感”最终拆解为层级、秩序、一致性、完成度、品牌匹配和可用性。

## 4. 权威规范

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines)：平台原则、布局、颜色、字体、图标、组件和无障碍。
- [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：分组、重要信息、适配、安全区和动态字体。
- [Apple Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：感知、适配、触控目标、运动和辅助功能。
- [Material Design 3](https://m3.material.io/)：颜色角色、排版、布局、组件、状态和设计 Token。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：对比度、颜色使用、文本缩放、重排、焦点和目标尺寸。
- [WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)：普通文字 4.5:1、大号文字 3:1。
- [WCAG 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：24×24 CSS px 或满足例外条件。
- [WCAG 不只依赖颜色](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color)：颜色不能成为唯一信息通道。
- [Ant Design 设计价值观](https://ant.design/docs/spec/values-cn/)：自然、确定性、意义感和生长性。
- [Ant Design 接近性](https://ant.design/docs/spec/proximity/)：通过空间关系表达信息分组与层级。
- [Ant Design 布局](https://ant.design/docs/spec/layout/)：栅格、适配、通用尺度以及“启发而非限制”。
- [GOV.UK Design System Styles](https://design-system.service.gov.uk/styles/)：经过验证的排版、色彩、间距与组件一致性。
- [Nielsen Norman Group: 10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)：系统状态、现实匹配、控制、错误预防、一致性、识别优于记忆等交互启发。

## 5. 继续更新方法

需要更新知识库时：

1. 优先检查用户指定作者页、站酷/优设的视觉细节与实战改稿文章。
2. 同时检查 Apple、Material、WCAG 等规范是否更新。
3. 只收录能转化成“检查信号—影响—改法—适用边界”的内容。
4. 合并重复规则，避免因文章数量增加而让检查清单无限膨胀。
5. 给所有固定数值标注适用平台和版本；无法确认时降级为启发。
