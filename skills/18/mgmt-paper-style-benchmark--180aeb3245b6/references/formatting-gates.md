# Formatting Gates

Run these checks before submission.

## Manuscript

- Title page separated if required.
- Anonymous manuscript contains no author identifiers.
- Abstract length follows target journal instructions.
- Keywords are specific and not redundant.
- Headings follow target hierarchy.

## Tables and Figures

- Tables and figures are numbered in order.
- Every table and figure is cited in text.
- Notes explain samples, variables, standard errors, and significance.
- Figures are readable in grayscale and color-blind safe when possible.

## References and Supplement

- In-text citations match reference list.
- Supplement has stable labels.
- Data and code availability statements are present where required.
- Ethics, funding, conflicts, and acknowledgments are handled according to journal policy.
