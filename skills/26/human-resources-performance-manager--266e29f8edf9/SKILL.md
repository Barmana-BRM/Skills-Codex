# 绩效管理助手

## 核心工作流程

### 1. 绩效体系选择

**主流绩效体系对比：**

| 体系 | 特点 | 适用场景 | 注意事项 |
|------|------|----------|----------|
| KPI | 结果导向、量化明确 | 成熟业务、可量化岗位 | 避免唯KPI论 |
| OKR | 目标对齐、挑战性 | 创新业务、知识工作 | 与考核适度分离 |
| BSC | 四维平衡、战略承接 | 战略管理、中高层 | 实施复杂度高 |
| MBO | 目标管理、自我控制 | 管理层、专业岗 | 需要成熟度 |
| 360度 | 多维反馈、全面评估 | 管理能力评估 | 文化适应性 |

**体系选择决策树：**
```
组织特征判断
├── 业务成熟度高 + 可量化 → KPI为主
├── 创新驱动 + 快速变化 → OKR为主
├── 战略转型 + 平衡发展 → BSC框架
└── 混合型 → KPI+OKR组合

岗位特征判断
├── 销售/生产 → 结果KPI为主
├── 研发/创意 → OKR+过程指标
├── 管理岗位 → BSC+360反馈
└── 职能支持 → KPI+行为指标
```

### 2. 目标设定与分解

**目标分解方法：**
```
战略目标分解
├── 公司级目标：年度战略目标
├── 部门级目标：承接公司目标
├── 团队级目标：承接部门目标
└── 个人级目标：承接团队目标

目标分解原则
├── 纵向承接：上下级目标对齐
├── 横向协同：跨部门目标配合
├── SMART原则：具体可衡量
└── 挑战适度：跳一跳够得着
```

**OKR设定框架：**
```
Objective（目标）
├── 定性描述：鼓舞人心
├── 聚焦重点：3-5个
├── 时间周期：季度为主
└── 挑战性：60-70%完成率

Key Results（关键结果）
├── 量化指标：可衡量
├── 结果导向：不是任务
├── 每个O下：3-5个KR
└── 评分标准：0-1.0
```

**KPI指标设计：**

| 指标类型 | 说明 | 示例 |
|----------|------|------|
| 结果指标 | 最终成果 | 销售额、利润率 |
| 过程指标 | 关键行为 | 拜访量、响应时长 |
| 能力指标 | 素质能力 | 专业技能、领导力 |
| 态度指标 | 行为表现 | 协作、主动性 |

### 3. 绩效评估流程

**评估周期设计：**
```
年度评估
├── 全面评估：绩效+能力+潜力
├── 薪酬调整：年度调薪依据
├── 晋升决策：职级变动参考
└── 发展规划：IDP制定

季度回顾
├── 目标进度：OKR/KPI达成
├── 问题诊断：障碍与支持
├── 目标调整：必要时修正
└── 反馈辅导：及时纠偏

月度跟踪
├── 进度同步：关键指标
├── 异常预警：偏差分析
└── 即时反馈：小问题及时解决
```

**评估方法组合：**
```
自评
├── 目标达成自述
├── 工作亮点总结
├── 问题与挑战
└── 发展需求

上级评估
├── 业绩表现评分
├── 能力素质评价
├── 综合等级评定
└── 反馈意见

360度评估
├── 上级评价：业绩+管理
├── 同级评价：协作+专业
├── 下级评价：领导+支持
└── 自我评价：对照参考
```

### 4. 绩效面谈与反馈

**绩效面谈流程：**
```
面谈准备
├── 回顾绩效数据
├── 准备反馈要点
├── 规划面谈结构
└── 预约时间地点

面谈开展
├── 开场：营造氛围
├── 回顾：绩效表现
├── 反馈：优点+改进
├── 倾听：员工想法
├── 共识：改进方向
└── 计划：下阶段目标

面谈跟进
├── 记录面谈内容
├── 跟进改进计划
├── 提供必要支持
└── 定期检查进展
```

**反馈技巧（STAR+AR）：**

| 步骤 | 说明 | 示例 |
|------|------|------|
| Situation | 具体情境 | "上周五的客户会议上..." |
| Task | 任务目标 | "你负责演示产品方案..." |
| Action | 具体行为 | "你准备了详细的对比分析..." |
| Result | 实际结果 | "客户当场决定签约..." |
| Alternative | 更好做法 | "如果能提前演练会更好" |
| Reinforce | 强化期望 | "继续保持这种专业态度" |

### 5. 绩效改进计划（PIP）

**PIP制定流程：**
```
问题诊断
├── 绩效差距：具体差距是什么
├── 原因分析：为什么产生差距
│   ├── 能力问题：不会做
│   ├── 态度问题：不想做
│   ├── 资源问题：做不了
│   └── 环境问题：不让做
└── 改进可能：是否可以改进

计划制定
├── 改进目标：明确期望
├── 行动计划：具体措施
├── 时间节点：里程碑
├── 支持资源：培训/辅导
└── 考核标准：如何评判

执行跟踪
├── 定期检查：进展跟踪
├── 及时反馈：问题指出
├── 调整支持：必要帮助
└── 结果评估：是否达标
```

**PIP文档模板要素：**

| 要素 | 内容 |
|------|------|
| 员工信息 | 姓名、部门、岗位 |
| 绩效问题 | 具体的绩效差距描述 |
| 改进目标 | SMART目标 |
| 行动计划 | 具体改进措施 |
| 时间周期 | 通常30-90天 |
| 检查节点 | 周期性回顾时间 |
| 支持措施 | 培训、辅导等 |
| 后果说明 | 未改进的处理方式 |

### 6. 绩效结果应用

**绩效等级分布：**
```
强制分布（参考）
├── S/优秀：10-15%
├── A/良好：20-25%
├── B/合格：50-60%
├── C/待改进：10-15%
└── D/不合格：0-5%

分布调整因素
├── 团队整体表现
├── 业务发展阶段
├── 历史分布情况
└── 特殊情况考量
```

**结果应用矩阵：**

| 应用领域 | 绩优员工 | 合格员工 | 待改进员工 |
|----------|----------|----------|------------|
| 薪酬调整 | 大幅调薪 | 正常调薪 | 不调/少调 |
| 奖金发放 | 高系数 | 标准系数 | 低/无系数 |
| 晋升机会 | 优先考虑 | 正常考虑 | 暂不考虑 |
| 培训发展 | 高潜培养 | 技能提升 | 改进辅导 |
| 岗位调整 | 扩展职责 | 维持现状 | PIP/调岗 |

## 最佳实践

- **目标对齐**：确保个人目标与组织目标一致
- **持续反馈**：不要等到年底才反馈
- **公平公正**：一致的标准、透明的流程
- **发展导向**：绩效管理的目的是帮助员工成长
- **区分对待**：对不同绩效的员工采取不同策略
