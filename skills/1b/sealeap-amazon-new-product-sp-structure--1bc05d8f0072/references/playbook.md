# 新品 SP 架构与异常诊断

## 三个决策维度

| 维度 | 要看什么 | 对结构的影响 |
|---|---|---|
| 生命周期 | 真实销量趋势、评论积累、库存与可售日期 | 新品测试、成长拓量、成熟提效的重点不同 |
| 消费者流量 | 搜索集中度、商品比较、场景/功能表达 | 选择核心词、长尾、ASIN 或类目入口 |
| 知识与数据 | 对商品、关键词和竞品的把握程度 | 决定探索顺序和测试范围 |

## 阶段矩阵

- 新品：用高相关意图校准方向，自动报告发现词和 ASIN；同时验证明确的核心词及目标竞品。产品相关关键词组可作为低人工投入的探索候选。
- 成长：将已验证词扩展到适当匹配方式与位置，验证相关/互补商品或类目，持续清除明确不相关的流量。
- 成熟：在利润约束下整理有效词、低成本长尾、品牌需求、自有商品与交叉购买；保留探索预算要有边际价值依据。

这些方向可以组合，不能把“新品必须先自动”或“所有投放必须同时开启”变成固定规则。单一入口与多入口也可能重叠，需通过报告观察实际分布和重复花费。

## 分组规则

按商品相关性、消费者意图、目标和预算控制需求分组。只属于特定变体的词，应限定相应商品范围。需要独立日预算时拆 campaign；只需改变商品/定向组织时可拆 ad group。关键词数、ASIN 数与账户容量由当前规则和管理成本决定，材料的 50 词、1-5 ASIN 是经验值。

## 异常分支

| 现象 | 先验证 | 可测试动作 |
|---|---|---|
| 自动转精准后曝光少 | 精准入口规模、竞价、预算、商品资格 | 单独预算实验或改变一个竞价/匹配变量 |
| 点击存在而转化差 | 意图、页面、价格、退货/评价、归因延迟 | 先修复已证实的根因，再实验 |
| 自动主要跑大词 | 产品相关性、流量份额、成本和搜索表达 | 补充真实场景表达，测试相关长尾 |
| 报告中 ASIN 多 | 实际 placement、商品目标与搜索词字段定义 | 比较对应成本及转化，不凭字符串直接加价 |
| 原有活动突然变差 | 可售/价格/页面变更、类目需求与竞品事件 | 先区分外部波动与内部设置问题 |
| 精准 ASIN 与拓展 ASIN 选择 | 已知竞品是否充分、需要探索的范围 | 对照验证精准与拓展入口 |

## 竞价与样本

计算当前 base bid、placement、受众与动态策略的合并影响，核验实际允许范围。课程旧界面的倍率和预算规则上限不直接复制。

1,000 次曝光、一周观察等只是材料示例。判断转化要看点击/订单样本、获客成本、归因延迟和用户损失上限；不能因为不足 1,000 曝光就无限继续烧钱，也不能仅达到该曝光量就认为结论可靠。

## 结构表

`marketplace / ASIN / campaign / ad_group / 入口 / 匹配方式 / 意图 / 目标 / 日预算 / 基础出价 / 调整规则 / 否定草案 / 主指标 / 停止线`。

关键词迁移、关键词组中的动态词变化、商品拓展结果均留版本和回读记录。
