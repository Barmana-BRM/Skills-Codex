# Drive repository changes with Claurst terminal coding agent

Use Claurst as a local Rust terminal coding agent for repo-aware planning, edits, command runs, tests, permissions, and multi-provider coding workflows.

## Prerequisites

Claurst CLI, release binary or npm package, model provider credentials configured in Claurst

## Installation

Install or set up from the source-backed instructions:

Install the npm package with npm install -g claurst, or install the latest release from https://github.com/Kuberwastaken/claurst/releases/latest. Configure provider credentials with environment variables or the Claurst connection flow, then run claurst for interactive TUI work or claurst -p "explain this codebase" for one-shot headless use.
