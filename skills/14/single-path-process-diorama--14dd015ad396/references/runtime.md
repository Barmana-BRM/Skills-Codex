# 运行条件与本地试用

## 必需能力

- 能读取本地 SKILL.md 和参考文档的助手。
- 实际图片生成工具，可把结果保存为文件；要修图时还需支持参考图片编辑。
- 能查看最终图片原尺寸和等比缩略图，而不只是读提示词。
- Python 3.10+，用于随包的零依赖 PNG/交付文件验证器。

本轮验证环境是内置 imagegen 的整图生成与参考图编辑、实际看图，以及本地 Python 标准库验证。未验证其他模型、其他客户端的自动加载行为或跨平台安装流程。具体模型底层版本未由本轮调用结果确认，不编造版本号。

Skill 不提供生图服务、账号、API 密钥、额度或模型权重。工具的账号、额度与费用按用户已有环境处理；本包不要求购买或登录 Midjourney，不依赖专有风格码。不要将参考图或用户故事发送到未经用户授权的额外服务。

## 不安装也能试用

1. 解压包，保留目录结构。
2. 把整个目录提供给能读取文件的助手，请它先完整读取 SKILL.md，再按需读取 references/qa.md。
3. 给流程、画幅和文字偏好；已清楚的信息不用重复问。

可以复制：

> 请先读取我提供目录里的 SKILL.md，用其中的单路径微缩剧场方法，把“收集素材 → 写成初稿 → 编辑校对 → 读者阅读”做成一张完整 3:4 图。纸木工坊风格，保留同一份稿件的身份，不要宫格。检查最终图后给我图片和一句说明。

自动安装不是运行前提。主分支的复制安装命令见 [README](../README.md)；已有安装先备份，并核对当前包版本。

## 能力不足时

- 没有生图工具：交付待执行方案/提示词，并明确“未生成图片”。不伪造最终图路径。
- 没有看图能力：明确“视觉未验证”；哈希或 PNG 结构检查不等于看图。
- 没有独立审查者：可以自审，但记录为自审，不称为独立验收。
- 当前工具无法完成编辑：说明限制；重新生成整图会有构图漂移，不能假装局部已锁定。
- 生成失败或达到约定修订上限：保留失败记录，报告未完成，不能无限消耗额度。

## 维护

修订说明或工具后运行随包单元测试；改变生成/审查规则时补充成对案例。示例发生变化时，重新看图、更新来源哈希，并区分旧版评测与新生产稿。PNG 验证器只证明文件结构，不证明物理、流程、版权或文案真实。
