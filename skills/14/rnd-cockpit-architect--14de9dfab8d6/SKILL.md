### SOA 服务化架构

#### 服务分类

| 类型 | 描述 | 示例 |
|------|------|------|
| 原子服务 | 不可再分的基础能力 | 车窗控制、空调温度设置 |
| 组合服务 | 多原子服务编排 | 一键离车模式、迎宾模式 |
| 场景服务 | 面向用户场景 | 疲劳驾驶提醒、儿童模式 |

#### 服务接口设计原则

```
1. 接口幂等性: 重复调用结果一致
2. 版本管理: 接口向后兼容
3. 超时处理: 明确超时时间和重试策略
4. 错误码规范: 统一错误码体系
```

### 通信中间件选型

| 场景 | 推荐方案 | 特点 |
|------|----------|------|
| 域内高频数据 | DDS (Fast-DDS/CycloneDDS) | 发布订阅、QoS保障 |
| 跨域服务调用 | SOME/IP | 请求响应、服务发现 |
| 云端通信 | MQTT / HTTP/2 | 轻量、穿透NAT |
| 诊断通信 | DoIP / UDS | 标准协议、诊断仪兼容 |
| 安全通信 | SecOC | 消息认证、防重放 |

### 功能安全设计 (ISO 26262)

#### ASIL 等级划分

| 等级 | 功能 | 安全要求 |
|------|------|----------|
| ASIL-D | 仪表关键显示（车速、档位、告警） | 最高安全完整性 |
| ASIL-B | 倒车影像、360环视、DMS | 中等安全完整性 |
| QM | 娱乐、导航、第三方应用 | 质量管理 |

## 输出规范

座舱架构文档应包含：
- 系统框图（域控视角）
- 服务目录与接口定义 (IDL)
- 通信矩阵（信号流向）
- 多屏显示策略
- 功能安全分析 (FMEA/FTA)
- 信息安全威胁分析 (TARA)
- 性能 KPI（冷启动 < 3s、热启动 < 1s、触控响应 < 100ms）
- 功耗预算与热设计
