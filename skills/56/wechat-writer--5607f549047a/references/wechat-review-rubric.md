# 公众号文章审稿门槛

审稿的任务不是打分，而是把能修的问题修好，并阻止不可靠内容成为“成稿”。

## 一、阻断问题

以下任一存在时不得通过：

- 核心事实错误、来源不支持或时效性未经核实。
- 虚构作者亲历、朋友同事、采访、对话、时间地点或感官细节。
- 标题承诺正文无法兑现，或包含虚假数字、身份、结果和保证。
- 引语、数据、图片、案例归属错误。
- 高风险法律、医疗、金融、安全或政策建议缺少必要来源与限制。
- 文章回答的问题与任务书不同。
- 关键代码、命令、模型名、URL 或步骤被改坏。
- 文章主要结构或措辞明显复制单一来源。

## 二、五维判断

每项 1-5 分。

### 1. 准确

- 5：核心和细节都可追溯；事实、推断、观点、个人材料清楚分开。
- 4：没有实质错误，少量低风险表述可更精确。
- 3：主结论可靠，但有需要弱化或补来源的次要内容。
- 2：多处具体主张缺证据或归因含混。
- 1：存在错误、虚构或误导。

### 2. 观点

- 5：核心判断明确，有推理、有反方、有适用边界，并提供新解释。
- 4：判断清楚，理由充分，边界基本完整。
- 3：有观点但部分章节只是资料堆叠。
- 2：主要是常识复述或新闻改写。
- 1：没有可识别的核心判断。

### 3. 实用

- 5：读者能据此行动、判断或选择，且知道前置条件和失败信号。
- 4：交付明确，有具体方法或决策条件。
- 3：有帮助，但细节不足或缺少验证方式。
- 2：建议抽象，难以执行。
- 1：没有读者可用的结果。

### 4. 合声

- 5：符合账号、栏目和用户样本，个性自然且不牺牲事实。
- 4：声音一致、得体，少量段落偏通用。
- 3：可读但账号辨识度有限。
- 2：语气混乱、促销或机械。
- 1：明显不适合目标账号或冒充不存在的作者经历。

### 5. 好读

- 5：开头迅速、章节持续推进、手机端节奏自然、结尾有力。
- 4：结构和段落清楚，少量重复或长段。
- 3：基本可读，但模板感、碎句或列表偏多。
- 2：跳跃、重复、长段或套话明显。
- 1：难以理解或无法完成阅读。

## 三、通过规则

- `pass`：平均分 ≥ 4，单项 ≥ 3，阻断问题为零。
- `revise`：可在现有材料内修正。必须直接修改后复审。
- `needs_input`：只有用户明确要求个人故事/立场，而现有材料不足且不能安全换框架时使用。

最多两轮：

1. 第一轮修事实、任务错位、结构和实用性。
2. 第二轮修声音、节奏、标题、摘要和细节。

第二轮仍不能通过时，删除不可靠内容、缩小承诺或更换角度，交付一个可靠版本；不要为了保留篇幅继续硬写。

## 四、逐项检查

### 任务对齐

- 文章是否回答读者真正问题。
- 核心判断是否贯穿章节。
- 每节是否推动一个主张或读者任务。
- 反方和边界是否被认真处理。
- 结尾是否交付任务卡中的行动或判断。

### 事实与来源

- 数字、日期、引语、研究、产品能力和当前状态是否逐项对账。
- 来源是否真的支持使用的措辞强度。
- 是否把相关性写成因果。
- 是否把宣传语写成事实。
- 搜索摘要和模型记忆是否被误标为已核实。

### 个人材料

- 每个第一人称事件是否出现在任务卡的个人材料中。
- 朋友、同事、客户、采访、对话和场景是否有用户材料或来源。
- 没有个人材料时，是否使用观察/问题/判断替代假故事。

### 标题与摘要

- 标题能否被正文完全兑现。
- 是否写清对象、场景或利益点。
- 数字是否真实且与正文一致。
- 摘要是否增加信息而不是复述标题。
- 是否存在恐惧、保证、身份和结果夸大。

### 移动端

- 前 120-180 字是否进入主题。
- 是否有过长段落、连续碎句或密集表格。
- 粗体、列表、引用和图片是否真的帮助阅读。
- 小标题是否推进内容而非重复标题。
- 结尾是否具体，不是“未来可期”。

### Humanization 完整性

- 套话、促销腔、模糊归因、强制三段式和统一节奏是否得到修正。
- 改写是否改变事实、确定性、来源、代码、链接和图片路径。
- 是否新增了虚构经历或表演式口语。

## 五、机械审计

运行：

```bash
node writer/wechat-writer/scripts/audit-wechat-markdown.mjs \
  writer/output/<article-slug>/article.md \
  --keyword "<核心主题>"
```

脚本检查 H1/H2、标题长度建议、摘要、正文长度、长段、图片路径、外链、参考资料、常见套话和疑似个人事件。它不能判断事实真假、观点深度、版权或作者身份。

不要为了让脚本“全绿”反复改写。先判断提示是否对当前文体真正有影响。
