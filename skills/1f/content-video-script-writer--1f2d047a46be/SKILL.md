# 视频脚本助手

## 核心工作流程

### 1. 视频类型与结构

**平台视频特点：**

| 平台 | 时长 | 节奏 | 风格特点 |
|------|------|------|----------|
| 抖音/快手 | 15-60秒 | 极快 | 开头3秒抓眼球、信息密集 |
| 视频号 | 1-3分钟 | 快 | 偏知识/情感/生活 |
| B站 | 5-15分钟 | 中等 | 深度内容、有梗有料 |
| YouTube | 8-20分钟 | 中等 | 结构完整、节奏分明 |
| 直播切片 | 30-90秒 | 快 | 高光/冲突/金句 |

**视频内容类型：**
```
知识干货型
├── 教程类：How to系列、技能教学
├── 科普类：XX是什么、原理解释
├── 盘点类：TOP10、年度盘点
└── 评测类：产品评测、对比测评

情感故事型
├── 个人故事：成长经历、转折点
├── 采访访谈：人物对话、观点碰撞
├── 纪实记录：Vlog、幕后花絮
└── 情景剧：剧情演绎、反转故事

娱乐搞笑型
├── 挑战类：热门挑战、趣味测试
├── 反应类：开箱反应、试吃试玩
├── 整活类：创意脑洞、恶搞模仿
└── 互动类：粉丝问答、弹幕互动
```

### 2. 短视频脚本结构

**黄金3秒开头公式：**
```
冲突开头
"你知道吗？90%的人都在错误地[做某事]"

悬念开头
"今天我要分享一个让我[惊人结果]的方法"

痛点开头
"还在为[痛点]烦恼？看完这个你就懂了"

反常识开头
"[常见认知]？大错特错！真相是..."

数字开头
"3个技巧，让你的[XX]提升10倍"
```

**短视频脚本结构（60秒）：**
```
0-3秒：钩子Hook（抓注意力）
├── 冲击画面/反常识/痛点/悬念
└── 目标：阻止滑走

3-10秒：承诺Promise（给期待）
├── 告诉观众看完能获得什么
└── 目标：建立观看动机

10-50秒：内容Content（给价值）
├── 核心干货/故事/演示
├── 信息密度高、节奏紧凑
└── 目标：传递核心价值

50-60秒：行动CTA（给方向）
├── 点赞/关注/评论引导
└── 目标：促进互动转化
```

### 3. 中长视频脚本结构

**B站/YouTube脚本框架：**
```
开场（30秒-1分钟）
├── 开头Hook：吸引注意力
├── 内容预告：本期要讲什么
└── 频道/个人介绍（可选）

主体（占总时长80%）
├── 章节1：问题/背景
│   └── 过渡句连接下一章
├── 章节2：分析/方法
│   └── 案例/演示支撑
├── 章节3：实操/应用
│   └── 具体步骤展示
└── 章节4：总结/延伸
    └── 核心要点回顾

结尾（30秒-1分钟）
├── 总结提炼：核心观点
├── 互动引导：点赞订阅评论
└── 预告铺垫：下期内容
```

**节奏控制技巧：**

| 元素 | 作用 | 使用频率 |
|------|------|----------|
| 金句 | 引用/观点输出 | 每3-5分钟 |
| 案例 | 具体化抽象观点 | 每个论点 |
| 数据 | 增强可信度 | 适量 |
| 幽默 | 调节节奏 | 适时 |
| 转场 | 章节过渡 | 每章节 |
| 互动 | 保持参与感 | 中间+结尾 |

### 4. 分镜头脚本设计

**分镜脚本模板：**
```
| 镜号 | 时长 | 景别 | 画面内容 | 台词/旁白 | 字幕 | 音效/BGM | 备注 |
|------|------|------|----------|-----------|------|----------|------|
| 01 | 3s | 特写 | 产品特写 | - | 品牌名 | 轻快BGM | 开场 |
| 02 | 5s | 中景 | 主持人 | "大家好..." | 同步 | - | 口播 |
```

**景别说明：**
```
景别类型
├── 特写：突出细节，情绪强调
├── 近景：人物表情，亲近感
├── 中景：上半身，对话常用
├── 全景：全身+环境，交代场景
├── 远景：大环境，建立氛围
└── 过肩镜头：对话场景
```

### 5. 口播文案技巧

**口播文案原则：**
```
语言口语化
├── 短句优先：15字以内
├── 避免书面语：不用"由于/因此/综上所述"
├── 多用"你"：建立对话感
└── 适当停顿：//标记换气点

节奏感
├── 重点强调：加重音/放慢
├── 长短交替：避免单调
├── 适当重复：强化记忆
└── 情绪起伏：有高有低
```

**口播稿标注规范：**
```
标注符号说明
├── //：换气/停顿
├── 【重】：重读强调
├── 【快】：加快语速
├── 【慢】：放慢语速
├── （动作）：肢体语言提示
└── [画面]：需要配合的画面
```

**口播稿示例：**
```
大家好//我是XX//

今天要跟大家分享【重】一个超实用的方法//

你有没有遇到过这种情况//（停顿看镜头）

[切产品画面] 就是这个东西//让我的效率【重】提升了3倍//

接下来我分3步给大家讲清楚//【慢】第一步...
```

### 6. 视频标题与SEO

**标题公式：**
```
数字+痛点+解决方案
"3个技巧解决XX问题，新手也能轻松学会"

悬念+结果
"用了这个方法后，我的XX直接翻倍了"

对比+冲突
"XX和XX到底怎么选？看完这个视频你就懂了"

热点+关联
"XX爆火的背后，隐藏着这个秘密"
```

**视频SEO优化：**

| 元素 | 优化要点 | 注意事项 |
|------|----------|----------|
| 标题 | 包含核心关键词+吸引力 | 不超过30字 |
| 封面 | 高清+文字+表情 | 符合平台调性 |
| 描述 | 关键词+时间轴+链接 | 前两行最重要 |
| 标签 | 核心词+长尾词+热门 | 5-15个标签 |
| 字幕 | 添加字幕提升SEO | 自动生成+校对 |

## 最佳实践

- **开头定生死**：前3秒决定80%的播放量
- **信息密度高**：每一秒都要有价值
- **口语化表达**：像跟朋友聊天一样
- **视觉优先**：能用画面说的不用文字
- **数据验证**：用数据指导内容迭代
