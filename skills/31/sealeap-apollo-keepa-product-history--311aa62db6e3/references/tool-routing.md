# Keepa 工具路由

优先使用已授权的 Keepa 连接器并发现当前工具 schema；也可使用其官方 API：`/product`，按 ASIN 请求 history 与所需统计字段。参考 [官方入口](https://keepa.com/api-docs/) 与 [能力文档](https://keepa.com/api-docs/product.html)，以执行时文档为准。

不能将商品详情、历史查询、文本搜索、Product Finder 互相当作同一接口。凭据由连接器读取，禁止打印含 key 的请求 URL。实际调用的参数、费用与批量上限需要按当前连接器确认。

## 实际执行

先复用范围匹配的授权导出或历史结果，再选择当前可用连接器。下列映射只验证了接口声明或本地代码，未验证在线鉴权、配额和真实返回。运行时重新查看工具 schema；存在同名工具也不等于字段、窗口、分页语义相同。

保留原始响应与业务状态，工具错误不得转成空数组。未提供的筛选器只可在已取得的样本上筛选，并披露样本边界。没有可用通路时交付缺口和可用数据分析，不编造接口或用其他数据源冒充指定提供方。
