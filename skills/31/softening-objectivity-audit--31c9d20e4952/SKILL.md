# 软化退化的增量、网格与能量客观性审计门

## I — 方法论骨架 (Interpretation)

软化模型必须证明结果由物理路径控制，而不是由求解器把路径切成多少步或网格切成多小控制。
若每次 UMAT 调用都再乘一个固定系数，调用次数就偷偷成为演化变量；相同载荷路径可能得到不同残余刚度。
局部刚度软化若没有特征长度、断裂能或其他正则化，损伤带宽和耗散通常会跟随单元尺寸。
审计必须同时改变增量切分和网格，并比较触发、峰值、峰后曲线、损伤历史和能量，而不是只看终值云图。
Job 状态、最后收敛时间、cutback 和切线质量也属于证据；能打开 ODB 不等于加载完成。
若审计失败，应把演化改写为可标定的物理变量并选择适合模型的正则化，再从同一基准重复测试。
现有示例只暴露了风险和缺失证据，并没有完成增量、网格或耗散能收敛；本 skill 因而是审计门，不是已验证的模型结论。
除固定因子递乘外，`dmg←dmg/e` 也会随中间 trial 指数路径和调用切分改变终值；文件名 Constant 不能解除这一离散依赖。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 同一加载路径改变 Abaqus initial/max increment 后，损伤、峰后曲线或失效时刻明显变化。
2. 网格细化后损伤带变窄、峰后耗散或承载力不收敛。
3. 代码含递归刚度折减、单元删除或局部应变软化，但没有 `CELENT`、断裂能或非局部尺度。
4. Job Aborted，却准备使用最后一帧 SDV/应力云图作最终结论。
5. 20/200 个增量给出相同峰值，却有不同终值刚度、删除时刻或耗散。

### 语言信号 (用户的话里出现这些就应激活)

- “增量越小损伤越严重 / increment-size dependence”
- “网格一细化结果就变 / mesh sensitivity”
- “怎么用 CELENT 或 fracture energy 正则化”
- “Job Aborted 但最后云图能不能用”
- “dmg 除以 e 为什么还会依赖步长 / dmg-over-e path dependence”
- “多一次零增量调用，刚度又下降了 / call-count dependence”

### 与相邻 skill 的区分

- 与 `tsai-wu-damage-state-machine` 的区别：后者定义损伤状态与更新语义；本 skill验证这种语义是否具有增量、网格和能量客观性。
- 与 `ddsdde-finite-difference-audit` 的区别：后者检查材料 Jacobian；本 skill检查路径和长度尺度。两者常需组合。
- 与 `umat-hierarchical-validation` 的区别：后者是通用验证梯度；本 skill是所有局部软化模型必须额外通过的专门门。

## E — 可执行步骤 (Execution)

1. **冻结基准问题与验收量**
   - 固定材料参数、加载路径、边界、单元族、稳定化开关和输出；定义触发载荷、峰值、峰后曲线、`dmg`、损伤带宽、内能/耗散及终止状态。
   - 完成标准：每次对照只改变一个审计变量，且指标可自动提取。

2. **运行增量切分矩阵**
   - 至少使用粗/中/细三档全局增量或受控材料点步数，保持相同物理终点；增加一次“相同状态重复调用/零附加载荷”故障注入。
   - 完成标准：给出每档的触发、`e` 路径、`dmg` 历史、峰后、能量和调用/折减次数；无新增物理演化时重复调用不得继续退化。

3. **运行网格矩阵**
   - 至少使用三档特征尺寸，保持几何、加载、单元公式和参数一致；记录 `CELENT` 或等价长度。
   - 完成标准：量化峰值、峰后耗散、损伤带宽和路径随网格的变化，并检查是否趋于稳定。

4. **审计能量、不可逆性和刚度**
   - 检查损伤不恢复、残余刚度下限、退化矩阵可用性、耗散非负、`SSE/SPD` 等宿主输出完备性及完整切线扰动误差。
   - 判停条件：任何 Job 未达到目标载荷、出现非有限量或能量符号错误，只能记为失败/诊断，不能进入收敛结论。
   - 完成标准：每个运行的 Completed/Aborted、最后时间、cutback 和能量平衡均被记录。

5. **判定并选择回炉方向**
   - 若增量数直接控制折减，改用应变、时间、能量或其他物理演化变量；若网格不客观，按材料证据选择断裂能/特征长度、非局部或黏性方案。
   - 完成标准：修复方案有标定参数和物理单位，不是为了曲线好看而任意加系数。

6. **完整复测并形成门结论**
   - 重跑步骤 2–4，报告通过阈值、未决项和适用网格/步长范围。
   - 完成标准：只有全部目标载荷完成且预设指标在容差内收敛，才能把软化模型标为“通过当前审计范围”。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 纯弹性或无局部软化的塑性模型，且结果不含退化/删除：使用通用验证链即可。
- 只想修复编译错误或局部残差：应调用语义调试或失败协议。
- 期望本 skill 自动选出唯一正则化：方案必须由材料、单元和标定证据决定。

## 相关 skills

- **depends-on**: `umat-hierarchical-validation`、`tsai-wu-damage-state-machine`——先明确要审计的退化状态律，再把增量、网格和能量检查嵌入独立验证矩阵。
- **contrasts-with**: 无——它是所有局部软化模型的附加审计门，不是某种损伤演化或固定正则化配方。
- **composes-with**: `wood-cdm-spatial-regularization-router`——本 skill 提供通用增量/网格/能量客观性门，后者增加木材模式、方向断裂能、裂带拓扑以及非局部/梯度路线选择。
