# A collection of small and easy-to-dialogue assistant projects

This catalogue contains three projects related to light helpers as an extension of the skills store.

List of items

#1. Companion-skill
**TypeScript**

A small-partner skill version based on TypeScript provides a complete skills system framework.

** Main function:**
Scene detection capability.
- Image generation.
- A personalized conversation.
Full Skill System Structure

**TypeScript, Node.js

** Fast start:**
```bash
cd companion-skill
npm install
npm start
```

Detailed documentation: [companion-skill/README.md] (./companion-skill/README.md)

#2. Companion-simple
**Python simplified version**

A simplified version of Python-based Python-based, with a focus on skills data management and Web presentation.

** Main function:**
- Skills data crawling and management
- 🌐 Web Interface Presentation
- API Service Integration
- Timed schedule.

**Technology warehouse:** Python, Flusk/FastAPI

# The relationship with the skill store

The projects are a tool and framework for the skills shop:

- **companion-skill**: Provide a skills development framework
- **companion-simple**: providing skills data management
- **asistant**: Provide a skills environment

# 📖 Use scene

1. **Skill developer**: new skills developed using copanion-skill
2. **Skill manager**: using copanion-simple management skills data
3.** Application Developer**: Build full application using Asistant
