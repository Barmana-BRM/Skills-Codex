# SP 站内外诊断手册

## 控制三个混淆

- Sponsored Products for creators 是 CPC 路径；Creator Connections 的品牌加佣按符合条件的销售计费。两者不能混成一个“达人费用”。
- 投放目的地为 Amazon 商品页，不表示曝光发生在站内。搜索广告位、站点选择和媒体渠道需要不同字段作证。
- CTR 或流量量级变化不能单独证明素材问题，也不能证明平台算法改变。

## 分解表

| 解释 | 最小证据 | 如何排除 |
|---|---|---|
| 渠道构成变化 | 可对账的渠道花费/点击占比 | 固定渠道内比较转化 |
| 点击变贵 | 同范围 CPC、位置及竞价记录 | 排除广告位结构变动 |
| 转化下降 | 成熟订单/点击、价格和可售状态 | 排除缺货、配送、Buy Box |
| 需求变化 | 同期需求指标和可比历史 | 不拿全店销售替代需求 |
| 商品预期不匹配 | 真实素材、PDP 与反馈证据 | 单一素材变量试验 |

## 实验卡

目标、活动和商品、唯一主要改动、媒体/站点资格、基准日期、费用上限、主指标、利润/订单护栏、归因成熟日、停止条件及回退。可比性不足时用观察性结论。结果不支持就停止扩大，不能以 CTR 好看替代净贡献。

不具备 API 或报告访问时使用授权导出，不把端点名称或报告存在当作已连接账户。
