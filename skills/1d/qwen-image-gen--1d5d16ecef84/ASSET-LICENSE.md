# Example provenance

All included images are locally generated fictional adult portraits or still-life/poster designs used in the owner's Qwen-Image evaluation. They are original demonstration outputs, not downloaded official examples, real-person references, or creator-source media.

The owner authorized preparing these selected cases for open source in Craft Skills. The original Skill and code are MIT licensed. Image examples are supplied with the same permission to reuse, while no exclusive rights or third-party model rights are asserted.

- `assets/examples/ab/`: original/rewrite pairs and their common generated reference. Checksums and generation parameters are recorded alongside the images.
- `assets/examples/portraits/`: three generated examples with prompts, dimensions, steps and seeds.

Public copies omit PNG runtime text/EXIF/time metadata. Their IDAT image streams are unchanged; no retouching, geometric correction or artificial Alpha was performed. The explicit asset hashes in the release check freeze the reviewed bytes. These Qwen outputs do not carry the embedded imagegen provenance marker used by some other skills; their provenance is recorded in a dedicated manifest instead.

Official PE model weights, complete system prompts and upstream implementation code are not included or relicensed. Upstream references are listed in the collection's THIRD_PARTY_NOTICES.md.
